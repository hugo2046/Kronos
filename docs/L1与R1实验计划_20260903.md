## 1. L1：长上下文先导（S1 的闸门）

**问题**：G1 的 alpha 随上下文长度是饱和于 90、继续上涨、还是已过峰？

**臂（冻结）**：

| 臂 | 权重 | 推理 L | 种子 | 变量 |
|---|---|---|---|---|
| L90 | G1（在位者，既有信号） | 90 | 100/101/102 | 锚 |
| L250-zs | G1 不动 | 250 | 100/101/102 | 仅推理上下文（微调几何 101 的因果前缀外推） |
| L500-zs | G1 不动 | 500 | 100 | 逼近 512 上限 |
| L250-ft | G1 s100 tokenizer 冻结；predictor 以 **lookback=250** 重跑 G1 配方微调（全 A 语料、epochs=15、CE 早停、seed 100） | 250 | 100 | 几何对齐版：消除"微调只见过 101 长窗"的混淆 |

其余逐字 canonical（H=10/N=20/T=1.0/top_p=0.9/seed=42）、csi300、mean 判据 + 四变体记录。
评估窗：backtest；L250-zs 三种子加跑 2025H2（可比性）。

**判据（冻结）**：

| # | 判据 | 冻结定义 |
|---|---|---|
| LC1 **靶存在** | L250-ft 与 L90(s100) 的配对差 > 0 **且** L250-zs 中位种子与 L90 中位的配对差 > 0（两条同向）→ "长上下文有增量，靶存在" |
| LC2 **需要换骨架吗** | LC1 通过 且 L500-zs(s100) − L250-zs(s100) > 0 → "逼近 512 仍在涨，S1（突破上限）立项"；LC1 通过但 L500 ≤ L250 → "**增量在 Transformer 上限内即可获得——采用 G1@L250 路线，S1 撤案**（换骨架无理由）" |
| LC3 显著 | 任一配对差 > 26pp 才许"显著"；带内只做方向描述 |
| LC4 关闭 | LC1 任一条 ≤ 0 → "上下文于 90 附近饱和/过峰，长上下文议题关闭，S1 撤案"，不做 L 网格（250/500 之外不加点） |
| 注册 | LC1 通过的 L250 臂（ft 优先）以规则文档注册进结算对照（复算级新臂） |

**预算**：L250-zs 3 种子 × 2 窗 ≈ 15h；L500-zs ≈ 6h；L250-ft 训练 ~1h + 推理 3h。合计 ~25h（约两夜，断点续跑）。

## 2. R1：读出头换目标函数（读出议题的终审实验）

**问题**：G5 三头全败，死因是"架构不适"还是"回归目标不适"？

**臂（冻结）**：复用 `g5_head/` 全部基建（G1 底座隐状态缓存、协议、训练窗），**唯一变量 = 损失函数**
MSE → **IC 损失**（每日截面批内 −Pearson(pred, label_z)，qlib 惯例），头族与 G5 一一对应：

| 臂 | 头 | 种子 | 对照 |
|---|---|---|---|
| R-lin | H-lin（833 参数） | 42/43/44 | G5 H-lin（MSE） |
| R-kda | H-kda（1.2M，容量对齐版） | 42/43/44 | G5 H-kda（MSE） |

评估：best 早停点，backtest + 2025H2，canonical 引擎。

**判据（冻结）**：

| # | 判据 | 冻结定义 |
|---|---|---|
| RC1 存活 | 某头中位种子 backtest 双基准 AER > 0 |
| RC2 目标效应 | 同头 IC 损失 vs MSE 的配对差（三种子中位）；> 26pp 才许"目标函数是死因"；带内"不可判" |
| RC3 对在位者 | 与 G1 s100 配对，同噪声框架 |
| RC4 **终审关闭** | R-lin、R-kda 中位均 ≤ 0 → "读出议题两目标（回归/排序）× 三头族 × 两底座终审关闭"，不做损失函数搜索 |
| 注册 | RC1 通过者需通过 2025H2 > 0 方可注册 |

诚实先验：15~25%——头仍在 2022-23 一段行情的标签上学，G5 的"早停段强、样本外崩"大概率重演。

**预算**：6 次头训练（缓存在盘）≈ 4.5h + 打分 ≈ 一夜内。
