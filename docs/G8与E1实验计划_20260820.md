## 1. G8：语料新鲜度（唯一变量 = 语料终点）

**配方（冻结）**：与 G1 逐字一致，仅改两处日期——

| 项 | G1 | **G8** |
|---|---|---|
| train | 2014-01-02 ~ **2024-12-31** | 2014-01-02 ~ **2025-06-30**（+6 个月） |
| val（早停） | 2025-01-01 ~ 2025-06-30 | **2025-07-01 ~ 2025-12-31** |

- 其余全部不动：ashares 并集、两阶段、epochs=15、lr/batch/步数封顶、种子 100/101/102、
  canonical 推理（L=90/H=10/N=20/T=1.0/seed=42）、csi300 评估池；
- **评估窗只有 backtest（2026-01-01~2026-07-24）**：2025H2 已被 G8 用作早停，
  对 G8 是准样本内，**禁止**用作其跨窗检验（如实披露）；
- 泄漏检查：val 末 2025-12-31 → 评估始 2026-01-01，早停选择未见评估窗任何数据 ✓。

**判据（冻结）**：

| # | 判据 | 冻结定义 |
|---|---|---|
| G8-1 存活/注册 | 中位种子 backtest AER(等权) > 0 且 AER(指数) > 0 → 通过 G1 同款准入门槛，**以规则文档注册为 G1v2025H1 臂**，forward 结算与 G1 同场对照——**新鲜度的终审在干净前向数据上，不在本轮** |
| G8-2 显著性 | 中位对中位差 > +26pp（噪声底）→ "新鲜度显著，滚动再训协议改半年度"（预期难达，如实设线） |
| G8-3 描述项 | 同种子配对差（G8−G1）三对必列，带内一律"不可判"措辞 |
| G8-4 否定 | 中位任一基准 ≤ 0 → "+6 个月新鲜度未过准入，语料新鲜度臂不注册"，不做终点日期搜索 |

## 2. E1：引擎缓冲带（唯一变量 = 换仓规则）

**规则（冻结，双阈值滞回）**：

```
持仓上限 k=50、min_hold=5、单边 15bp、每日净换手上限 n=5 只——全部沿用
卖出：持仓股当日信号排名跌出前 100（且已过 min_hold）才卖
买入：从未持仓股中按排名从高到低补足至 50，仅限排名 ≤ 30 者
候选不足时允许持仓 <50（等权重分于现有持仓），不强行补足
```

（canonical 的规则是"跌出前 50 即在轮换名单"——E1 把买入门槛提严到 30、
卖出门槛放宽到 100，滞回带 30~100 吸收排名噪声抖动。）

- **输入**：既有 G1 三种子 mean 信号（两窗全用：2025H2 + backtest，E1 不涉训练无准样本内问题）；
- **实现**：新包 `e1_buffer/`，缓冲带引擎为新模块，**不改** `paper_replication/engine.py`；
  单测：min_hold 不变式、持仓数 ≤50、无前视（t 日决策仅用 t 日信号）、同输入重放逐位一致；
- 零 GPU，纯重放，数小时。

**判据（冻结）——利用成本侧的确定性优势**：

| # | 判据 | 冻结定义 |
|---|---|---|
| E1-1 机械判据 | 日均换手较 canonical 下降 ≥ **30%**（确定性量，不受噪声底影响，精确可读） |
| E1-2 无害判据 | E1 净 AER(等权) 中位与 canonical 中位之差 > **−26pp**（滞回引入的信号迟钝未显著吃掉成本节约） |
| E1-3 注册 | E1-1 **且** E1-2 → "缓冲带候选成立"，以规则文档注册（同 C 系），forward 结算同场对照 |
| E1-4 否定 | E1-1 未达 → "滞回带压不动机械换手底，成本侧该形态关闭"；不做阈值搜索（30/100 之外不加点） |
| 呈现 | 三段分解必列：成本节约（换手降幅 × 30bp，确定性）/ 毛 AER 变化（噪声域）/ 净 AER（两者合成） |
