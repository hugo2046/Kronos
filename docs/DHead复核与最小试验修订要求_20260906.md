## 2. 必修项与验证

### R1：D2比较实际选定的模型

位置：dhead_distill/evaluate.py:d2_unlock_condition，cli.py:_eval_fidelity。

传入两臂result.json里的best_epoch，按epoch标识取对应history行：

- D0：best-D checkpoint那一行的val_task；
- D1：best-task checkpoint那一行的val_task。

禁止改选D0的best-task来匹配比较；fidelity分数也必须绑定同一checkpoint身份。

必须新增多epoch反例：D0 epoch0 (val_d=.1, val_task=.5)、epoch1 (.2,.3)，D1选定点task=.4。D0实际选epoch0，故改进条件为.4<.5，应通过；当前实现比.4<.3会误拒。现有单epoch测试无法暴露此错。缺best_epoch、重复epoch、对应行不存在均显式报错。

### R2：补回逐样本收益还原信息

位置：data.py / train.py:DayTensor、_materialize_days / head.py / cli.py:_predict_arm。

scale_source是**损失权重**，不等于输入窗口的价格尺度，不作为此项修复。

采用明确的仿射还原契约，学生头先输出标准化未来close z，再还原收益：

```text
mu_i = mean(过去90日原始close)
denom_i = std(过去90日原始close, ddof=0) + 1e-5
a_i = denom_i / close_t
b_i = (mu_i - close_t) / close_t
r_hat[i,h] = a_i * z_hat[i,h] + b_i
score_i = mean_h(r_hat[i,h])
```

mu、denom、close_t必须只由历史输入算出，且与教师close反归一化计算的dtype和顺序对拍。保持原始收益标签、教师收益目标和原S/D/I定义；对raw-return输出计算损失，避免又叠加loss尺度改动。scale_source默认train_real_std，本试验不调该字段。

逐样本a/b经显式张量字段传给输出还原，不能靠隐藏全局状态或从未来标签求得。新头输出语义用output_space='normalized_close_affine_return'进入新协议身份；旧head checkpoint禁止当作新语义的起点。

必须新增反例：两个过去90日OHLC窗口仅相差加法平移900，标准化输入相同，close_t=101/1001；同样未来价格增量1对应收益1/101与1/1001。注入相同z_hat时，还原应与教师公式一致，且能区分这两个收益。再测改变未来数据不会改变a/b；训练与推理用同一还原函数；正常/低波动/末日离群样本均覆盖。

这项缺口也来自Codex原设计，不能归责为zcode没有照方案做。

### R3：教师新旧产物可共存，评价校验闭环

- 教师schema新增版本，并允许明确run_namespace，例如v11-rev2；目录身份区分eval模式和生成协议，不在旧v1目录追加字段或覆盖分片。
- 原始历史清单可只读复用，但生成/训练manifest明确区分dataset identity、teacher identity、student identity。改变学生输出空间不应被误称为同一个教师缓存版本；是否复用必须核对完整依赖。
- train和evaluate两条入口都核验当前teacher权重hash；当前cli._teacher_array_for没有传expected_weight_hash，需补齐。
- 教师生成与装载比对N/T/top_p/top_k、replica数、生成长度、dtype和实际eval状态；不能只信任写死的model_eval=True。
- 每个教师分片保存并验证内容hash、shape、样本键及有限性；有效NPZ内只改一个数，也必须被装载层发现。不要把done=1当内容校验。
- 学生checkpoint、验证summary绑定代码hash、权重hash、清单hash、scale及输出语义。恢复不一致时拒绝混用，保留旧产物。

## 3. v1.1 rev2 最小试验（运行前写入方案）

修复前置完成后，仅执行以下历史试验。范围仍为既有pilot前8个训练日，最多512个样本，seed42。main、D1/D2、forward与经济评价均不解锁。

### 3.1 教师与数据

- 只读复用这8日的既有输入清单，不取新行情；按eval态教师重新生成3 replicas，新namespace保存。
- 日历、随机种子映射、N20、T1/top_p.9/top_k0保持原口径并写完整身份；教师与学生实例分离。
- R_train由**相同8日样本**的replica1/2按日等权MSE_norm计算；该尺度使用既有pilot训练清单上计算并冻结的scale，两个学生臂完全一致。
- 原v1的val教师缓存不被覆盖。当前最小试验不必重生成val；若报告跨窗口噪声，单独标识而不混为训练门槛。

### 3.2 两个可解释对照

- A：修复eval教师、旧raw-return预测接口；
- B：同一eval教师、增加R2仿射还原的新接口。
- 两臂头骨架、随机初始化参数、样本次序、优化器一致；头权重从同seed全新初始化，各200 epoch，无早停，lr3e-4、wd.01、clip1、纯蒸馏D。B与A差别只有输出语义/仿射还原。
- 这两臂用于定位接口影响，不选择最好epoch，使用最后epoch作为冻结诊断点。记录epoch0（优化前）以及每个训练epoch的完整指标。
- 最小试验累计GPU预算1小时。预估超限则先提交已完成代码/诊断和资源说明，不减少样本或临时改epoch制造可比结果。

### 3.3 指标与允许结论

对每臂按日期等权报告：训练D(r0)、独立replica1保真E、R_train、学生信号截面方差、逐日Spearman、梯度范数、非有限值计数、训练曲线；报告replica两两相关性。

同时报告仅由这8日训练target算出的全局逐期限均值基线。若另列“当日教师截面均值”，明确它是事后oracle参照，不能作为可部署基线，也不能据它的比较证明“只学到了均值”。

- 工程检查：末epoch训练D≤R_train，记录是否满足；该比较是预设工程诊断，不是统计显著性。
- 通过只说明该配置在这些样本上达到拟合容差；若没有逐股方差/排序证据，不能进一步声称逐股信息已学会。
- 不通过写“本配置在本预算下未通过最小拟合检查，原因待诊断”。不据此判容量不足、架构无效或扩大搜索。
- sqrt(R_train)是两replica差值RMS，不能直接当单replica噪声。train-mode与eval-mode的R之差不是可直接相加分解的dropout占比；生成分布会一起改变，只记录模式敏感性。
- A/B差异只有本批样本诊断含义，无泛化、收益、main解锁含义。
