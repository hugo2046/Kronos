> 本文提出一轮新的预注册方案，不修改既有实验的冻结判据，也不重写历史结论。

**目标**：构建以 Kronos 为底座的两遍条件生成模型，在相同数据、采样和评估口径下击败 canonical baseline F0_mean；同时接受 G1、免费动量 M 和机制对照的检验。历史胜出最多称为候选，最终结论依赖新登记的前向窗口。

**架构**：冻结官方 Kronos tokenizer、Transformer、DependencyAwareLayer 和 DualHead。第一遍从历史行情获得隐状态，新增小型状态编码器把它压缩为四个连续状态 token；第二遍将状态前置于相同历史并重新编码，仍以原粗细 token 生成头预测未来十日行情。

**技术栈**：Python 3.10+、PyTorch、numpy/pandas、scipy/statsmodels、pathlib、loguru、pytest；复用现有行情数据入口和 engine_v2。文档字符串采用 Sphinx，关键逻辑用中文注释。

## 2. 研究命题与方法选择

论文的启发是：后形成的状态若能在下一遍读取材料之前出现，可能改变材料的条件化表示。其研究没有验证金融预测，也不能保证 L=90 的 Kronos 存在相同瓶颈。

**TAS1 命题**：在不增加历史长度、不更换生成式输出、不增加输入信息的条件下，用第一遍历史表征生成的状态指导第二遍历史编码，能否改善十日截面预测？

| 方案 | 评价 | 本轮决定 |
|---|---|---|
| 把第一轮预测 K 线直接拼到历史前面 | 无新训练，但合成未来容易被模型误读为更早行情，时间戳语义不清 | 不采用 |
| 可训练连续状态 token + 冻结生成底座 | 状态与行情语义可分，保留预训练模型，能做严格同状态位置对照 | 主方案 |
| 重训循环 Transformer、扩散或其他骨架 | 成本和混淆因素多，难以归因于状态前置 | 不在本轮范围 |

这是基础模型之外新增可训练条件接口的模型改造，不是普通提示词技巧。第一遍使用隐状态代理而非自然语言推理轨迹，须称为“受 Trace as State 启发的变体”，不能称为论文复现。

## 3. 完整模型定义

### 3.1 输入与第一遍

对决策日 t、股票 i，取 X∈R^(90×6)，所有真实数值的可用时间不晚于 t。

1. 只用 X 计算每列均值与标准差；未来标签不得参与归一化。
2. 经冻结 tokenizer 生成粗细 token，用原 token embedding 与日历 embedding 编码。
3. 经冻结 Kronos 主干得到 H∈R^(90×d)。d 从 checkpoint 配置读取，不能硬编码成另一个规格。
4. 第一遍在 eval + no_grad 下计算；H detach。它不需要自回归采样，也不依赖未来实际收益。

将 90 个位置按顺序切为 [0:23]、[23:46]、[46:68]、[68:90]。每段均值与最后位置拼接：

Z_j = concat(mean(H[segment_j]), H[89])，j=1..4，Z∈R^(4×2d)。

第一遍摘要完全由历史构成；它提供额外计算与重新组织，不提供新的市场信息。

### 3.2 状态编码器

S_j = W2·GELU(W1·LayerNorm(Z_j)+b1)+b2+e_j。

- 共享 MLP：2d → 64 → d；四个可训练槽位 embedding e_j。
- 增加一个可训练查询 token q，表达“从这个历史终点开始预测”。
- 状态不经行情 tokenizer；没有伪造 OHLCVA，也没有伪造历史日期。
- 所有新增模块 dropout=0；初始化遵循 PyTorch 确定性种子，MLP 输出使用小尺度初始化。
- 可训练参数仅包括 LayerNorm、MLP、e 和 q；LayerNorm使用可训练缩放与偏置、两层Linear均带偏置，参数量公式为 202d+64。若 d=832，为168128（约16.8万）；最终必须用 numel 实测。
- 原模型 embedding、time_emb、全部 Transformer blocks、norm、dep_layer、DualHead 与 tokenizer 均冻结。

### 3.3 第二遍与位置对照

```text
PRE : [S1 S2 S3 S4] [历史90个token] [q] [已生成未来token]
POST: [历史90个token] [S1 S2 S3 S4] [q] [已生成未来token]
```

q 在两种布局中位置相同，第一天 logits 均取 q；随后第 k 天 logits 取第 k−1 个未来 token。这样避免把“从哪个类型的位置读出”混入前置/后置比较。

- 两臂使用相同 θ、φ、S、历史、q、时间特征与采样数；只改变 S 相对于历史的位置。
- 历史和真实未来 token 保留原日历 embedding；S、q 不添加日历 embedding。
- 使用排列后的 RoPE 位置。整个位置处理属于待测干预，不声称已隔离所有位置编码效应。
- 必须重新计算第二遍历史表示；不得复用第一遍的历史 KV/隐状态冒充条件化重读。
- 最长第二遍输入为 4+90+1+9=104；若在生成后校验完整序列，则为105，均小于512。
- S 固定于决策日 t，一次计算后供20条采样复用；十日生成过程中不重算 S。
- 预测的粗细 token 仍由原 DependencyAwareLayer 和 DualHead 生成。
- tokenizer 解码时只拼真实历史 token 与生成的未来 token；连续 S 和 q 永远不能进入 tokenizer.decode。
- 最终聚合必须走原 mean 定义，不新增直接收益回归头，不做 F0/TAS 信号混合或择优回退。

### 3.4 训练时的因果性与梯度

训练目标仅包含未来10步粗/细 token 的平均交叉熵，不对历史位置算预测损失。因为状态总结了完整历史，把历史位置也当因果训练样本会改变其信息集合。

L = mean_{k=1..10} [CE(s1_logits_k,y1_k)+CE(s2_logits_k,y2_k)]/2。

- teacher forcing 只输入前 k−1 日未来 token；第 k 日细 token 可条件于同日真实粗 token，这是原层级分解。
- 用历史窗口归一化参数变换未来训练标签；未来值只出现在监督目标及合法的 teacher-forcing 前缀。
- 第二遍 θ.requires_grad=False，但不能包在 no_grad 中，否则 φ 没有梯度。
- 原 cross-attention 的 is_causal 跟 self.training 联动。新 wrapper 必须显式控制 teacher-forcing 因果掩码；不能仅把冻结底座设为 eval 然后默认它仍有训练因果掩码。
- 新增 wrapper 使用原冻结投影权重，显式实现因果 s2 attention；训练和 teacher-forced 验证均用相同掩码。自由生成时只传已知前缀。
- 必须用单步逐段 teacher forcing 与批量 teacher forcing 的 logits 对拍，防止粗细 token 对齐或未来泄漏。

## 4. 实验臂与归因

仅训练以下两个模型族，每族种子42/43/44。第一阶段只运行42；是否启动其他种子由下文固定规则决定。

| 编号 | 定义 | 用途 |
|---|---|---|
| B0 | 原始 F0_mean，N=20 | canonical 基准 |
| B1 | 原始 F0，较大 N 的预算参照 | 检查额外推理成本能否用简单采样获得；不改变 canonical |
| B2 | 既有 G1_s100/s101/s102 mean | 已有微调方法参照，不挑最好种子 |
| B3 | 原始10日动量 M | 免费方法参照 |
| C0 | STATIC：用训练集固定平均 Z 代替每个样本 Z，训练同结构 MLP 与 q | 检验静态提示与额外训练是否足够 |
| T-PRE | 动态状态前置 | 唯一主候选 |
| T-POST | T-PRE 同一个 checkpoint、同一个 S，改为后置 | 检验位置效应 |
| T-SHUFFLE | 同 checkpoint，把同日股票状态按代码排序循环错配一位，再前置 | 状态与本股票对应性的破坏诊断 |

H1a-kda_s42作为历史结果描述参照，不重新训练、不参与选择主模型。它的单窗较高 IC 不构成跨窗成功基准。

训练 T 和 STATIC 时固定按 optimizer step 奇偶交替 PRE/POST，比例1:1。各自仅产生一组共享参数，使 POST 在训练中也被见过；不能只训练 PRE 再把 POST 的分布外失败解释成位置机制成立。

STATIC的固定平均Z由4096个训练样本估计：将合法(date,code)键按SHA256字典序排列取前4096个，按状态槽位分别取均值；集合不足4096则用全部并记录数量。该样本清单、平均Z与底座哈希在训练前固定，三个种子共用；不遍历全量隐状态缓存，也不从验证/评估窗口估计均值。

SHUFFLE 仅为推理破坏实验，存在分布外混淆；单独的 SHUFFLE 退化不足以证明机制。对当天股票数小于2的样本报错，不能跨日期抽取状态。

B1 的 N 在性能试跑后、结果开封前由确定性规则固定：用训练期固定200个样本测得 T-PRE(N20)/B0(N20) 的 GPU 时间比 r，N=20×max(2,ceil(r))，最大80。超过80仍不能覆盖预算时标为“预算未匹配”；无性能结果驱动的 N 搜索。它只是至少匹配推理预算的诊断，不是精确 FLOPs 相等，也不匹配训练成本。

推理采样主 seed=42。PRE/POST/SHUFFLE 使用相同显式随机数流；新增 q 或状态构造不能消耗采样 RNG。记录相同 seed 不等于每次采样结果相同，也不等于完全相同的计算成本。

## 5. 数据、训练和模型选择

### 5.1 时间分割

| 用途 | 范围与规则 |
|---|---|
| 训练语料 | 现有全A历史语料，2014-01-02起，所有目标日≤2024-12-31；用交易日历反推最后合法决策日 |
| 验证与选择 | 2025H1，全部未来10日目标必须仍在2025H1内 |
| 历史评估一 | 2025-07-01～2025-12-31 |
| 历史评估二 | 2026-01-01～2026-07-24 |
| W1/W2旧窗口 | 已落入本轮训练/验证，不作为新模型样本外证明 |
| 原 forward | 2026-07-25起的既有登记按原协议封存，不提前分析、不读取其信号或成绩 |

训练全A语料的历史覆盖、复权、停牌与并集语义沿用现有来源并披露，不把“PIT并集”声称为每一天完整PIT训练池。评估与验证统一使用每日PIT CSI300。

历史评估尾部结算只使用既有协议已经公开用于旧决策日结算的价格缓冲；不得据此扩展到2026-07-25以后新的信号日。新模型不能把任何真实未来值纳入S。

两个历史评估窗口都被项目反复观察过，属于研究者层面的已知窗口。时间上不进入训练仍不等于研究意义上的独立检验。

### 5.2 固定训练配方

- AdamW，lr=3e-4，weight_decay=0.01，梯度范数裁剪1.0。
- 有效batch=64，按样本均匀抽取合法历史窗口；两模型族使用相同批次序列。
- 共4000次优化步，1000/2000/4000三处保存checkpoint。固定学习率，不做warmup/lr网格。
- 每个checkpoint在完整、合法的2025H1验证决策日自由生成，N=20；用k=10日截面RankIC均值选择，平局到1e-6时取较早checkpoint。
- T仅按PRE验证分数选checkpoint；POST必须用同一checkpoint，不允许另选最优POST。STATIC按自己的PRE验证分数选择。
- val CE、生成合法率、loss曲线均报告，但不替代选点规则。
- 每模型族三种子用同一规则各选一点；不能看历史评估后改步数或挑seed。
- batch OOM时先降microbatch并梯度累积保持有效64；不得因此改变学习率、步数或数据量。
- 参数和步数是本方案的预算选择，不声称为经验最优。若训练不足或CE改善不转化为IC，按结果记录，不在同一轮临时换排序损失。

## 6. “击败baseline”的分层定义

### 6.1 主统计量

沿用修正后的累计RankIC：IC_t=Spearman(signal_{i,t}, close_{i,t+10}/close_{i,t}−1)。k=10唯一主终点；k=1/5是附表。

- 所有比较先按(date,code)显式对齐；股票列重排不能改变结果。
- 在同一预先构建的合格集合上评价所有臂，不能靠某臂缺失值改变比较股票池。
- 每天至少30只；模型本身产生缺失应使本阶段质量门禁失败，不能选择性dropna后继续报胜。
- 逐日IC是观测单位，股票数、采样数、训练种子数均不是独立时间样本数。
- 配对差 d_t=IC_T,t−IC_B,t，必须在同日同股票集合上求差，再计算均值与HAC标准误。
- Newey-West主lag=9；固定lag=20作为敏感性附表，不能选择显著的lag。
- 按真实交易日顺序计算合并统计；存在缺失日或断开的窗口时，不能删空档后伪造相邻序列。须分连续段累积协方差并记录日历间距。
- 配对双侧p值与95%区间一并报告；多重比较用Holm校正。历史窗口p值仅为诊断，不消除历次研究选择偏差。

### 6.2 历史阶段门槛（决策规则）

**阶段A：seed42快速淘汰，不作显著性宣称。** T-PRE在两个历史窗口IC都>0，且相对B0配对IC均值各窗都>0，才启动42之外的两种子；否则本方案停止并报告原因。

**阶段B：三种子后确定固定候选。** 对每只股票的三个T-PRE原始mean信号取算术平均，形成唯一候选E-PRE；POST、STATIC、SHUFFLE同样聚合。G1使用其100/101/102原始信号算术平均，另并列每个种子，不挑最优。

历史进入新前向的条件全部满足：

1. E-PRE两窗k=10 IC均值均>0，合并IC>0；三种子中至少2个各自在两窗IC均>0。
2. E-PRE相对F0的配对IC提升两窗均>0，合并提升≥0.005。0.005是本轮人为预设的最低实际增量，不是论文保证或行业常数。
3. E-PRE相对G1集合、M、B1的配对IC提升两窗均>0。
4. E-PRE相对E-POST、E-STATIC的合并配对IC提升>0；六个对比（F0/G1/M/B1/POST/STATIC）一并报告Holm校正结果，不把历史p值当独立确认。
5. v2两窗双基准AER均>0；相对F0、G1集合、M的净收益差均值每窗都>0。未通过时可以记录“预测改进候选”，但不宣称可交易胜出，也不进入本计划的正式前向确认。

三种子集合用N=20/种子，成本是单模型三倍。B1须另按集合E-PRE的实测推理时间用同一规则冻结N（上限80）；单种子B1和集合B1分别标识。所有臂报告实际GPU秒，不能用集合精度声称相同成本胜出。

### 6.3 独立前向确认

只有阶段B通过后，生成新的manifest，冻结代码/权重/数据规范/模型集合/对照/成本/N/统计规则的哈希。新的首个决策日必须晚于manifest冻结，并在首个决策日前完成登记；不追溯回填过去日期，不加入旧forward冒充原生登记臂。

- 固定126个交易日作为首个新确认窗口，等最后决策日10日标签成熟后一次开封。
- 同时登记E-PRE、F0、G1集合、M、B1、E-POST、E-STATIC；不得中途换权重或混合比例。
- 两个预设63日半窗只在最终一起开封；E-PRE相对F0的IC提升须两个半窗均>0。
- 正式“击败canonical baseline”：全窗E-PRE平均IC>0、对F0平均ΔIC≥0.005，并且自身IC与对F0配对差这两项检验均通过下述七项检验族的Holm校正。单项95%区间作为效应不确定性的描述，不冒充同时置信区间。
- 正式“优于项目既有方法”：在前一条件上，对G1集合与M的配对IC差也通过正向校正检验。
- “状态前置机制获得支持”：对POST与STATIC同样通过；SHUFFLE仅作支持性诊断。
- IC检验族固定7项：自身IC>0，以及对F0/G1/M/B1/POST/STATIC六个差>0；采用双侧p值Holm，均值方向必须为正。正式判决以校正p<0.05和预设效应门槛为准；未经校正单项区间只作描述。
- 组合成功另行检验：v2净收益相对F0/G1/M的每日差，HAC(lag=20)与Holm三项校正；同时双基准AER>0。仅IC通过只能称“预测改进”，不能称“可交易alpha已确认”。
- 区间含零或样本不足时判为“未确认”，不延长窗口直到显著。后续新研究另行预注册。

正式运行前用验证期配对差方差计算126日的可检测效应并记录。若对0.005明显缺乏功效，先在不看前向数据的条件下修订样本量并重新冻结；不得跑完再补样本。126日是起始设计，不是显著性的保证。

## 9. 预算、失败处理与停止规则

不直接沿用旧实验“一个晚上”的耗时估计。P0在目标GPU实测20个训练步、固定200个历史输入推理与单日完整CSI300评分，记录峰值显存、秒/步、秒/日、I/O和参数量。

训练预算估计：模型族数×种子数×4000×秒/步；另加每族每种子的三次完整验证推理、历史臂评分与基线预算参照。预留25%工程余量，不把第一遍状态成本漏掉。

初始上限：P0/P1 GPU2小时，P2 GPU24小时，条件P3再48小时。用户后续已要求 zcode 按 handoff 接力执行：在 P0 核实环境、冻结配置且前置门禁通过后，可在上述预算内依序推进。预计超出时在历史结果开封前报告预算差异，另行确认资源安排；不擅自减少股票、采样或测试日后仍声称同口径。

- 数值NaN、覆盖失败、未来泄漏、状态梯度为零：工程失败，修复后同协议重跑，保留失败记录。
- loss下降但历史IC不增：研究失败，不能改目标后计作同轮成功。
- PRE与POST都赢F0但相互不分：可能是适配/额外计算有用，位置机制未确认。
- PRE与STATIC无差：样本动态状态没有显示额外贡献。
- 一窗赢一窗输：跨窗失败，不按行情事后造门控。
- F0赢了但M/G1或预算参照没赢：只报告局部改进，未达到本轮完整目标。
- 只用相同历史的新结构继续试验不能产生新的独立证据；失败不自动扩张状态数、层数、L、损失或底座网格。
