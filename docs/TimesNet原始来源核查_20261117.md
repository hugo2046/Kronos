# TimesNet 原始来源核查

核查日期：2026-11-17。仅核查原论文和作者代码；未启动实验、未修改模型。OpenReview PDF 遇到浏览器验证，使用同论文 arXiv v3；代码链接为核查时的 main 分支，未固定提交。

## 机制与证据边界

TimesNet 对隐表示做 FFT，选择显著频率，将序列按对应周期补零并折叠成二维结构，用共享的多尺度二维 Inception 卷积同时建模周期内与周期间变化，再按频谱幅值的 softmax 加权、还原并加残差。它是通用时序骨干，不是专为金融设计的因果解码器。[论文 §3](https://arxiv.org/pdf/2210.02186)

金融相关基准包括 8 变量、日频的 Exchange；M4 也包含金融类序列，不能称为“完全没有金融数据”。长预测指标是 MSE/MAE，短预测是 SMAPE/MASE/OWA。论文表 1、表 8 的预测基准并未建立股票横截面选股、交易成本后收益、Sharpe 或回撤方面的证据。因此，通用预测表现不能直接推出股票交易有效。[论文表 1、表 8](https://arxiv.org/pdf/2210.02186)

## 官方实现的关键区别

- `FFT_for_Period` 对 `[B,T,C]` 的频谱幅值先按 batch、再按通道求均值选 top-k，故**同一批次共享候选频率/周期**；返回的聚合幅值则按样本保留。周期是 `T // frequency`，不是每个样本单独选周期。[官方 TimesNet.py](https://github.com/thuml/Time-Series-Library/blob/main/models/TimesNet.py)
- 推论：批次组成变化可能改变同一样本的结果；这不是 BatchNorm 的训练模式问题，`eval()` 也不会消除。若一批内混入预测时点尚不可得的样本，共享选频会形成额外信息通路；不能仅因 batch 共享便断言原实验泄漏。[实现依据](https://github.com/thuml/Time-Series-Library/blob/main/models/TimesNet.py)
- `Inception_Block_V1` 使用奇数核 `Conv2d(..., padding=i)`，双侧邻域没有因果掩码。因此按原时间顺序展开后，内部位置可依赖后续位置。[官方 Conv_Blocks.py](https://github.com/thuml/Time-Series-Library/blob/main/layers/Conv_Blocks.py)

## 接入自回归模型的风险判断

官方预测路径只使用已知 `x_enc`，先以线性层扩展时间维，再一次输出预测区间；双向处理已知历史本身并不等于使用真实未来。但若直接插入带 teacher forcing 的逐 token 自回归训练，序列末端可能包含前面预测位置的真实目标：双侧卷积、全序列 FFT 和整窗归一化都会破坏逐位置因果性。后面的 causal attention mask 无法撤销前面已经混入的信息。此项是依据代码作出的迁移风险推论，不是论文报告的漏洞。[官方预测路径](https://github.com/thuml/Time-Series-Library/blob/main/models/TimesNet.py)

若未来验证，应优先将其限制为只读预测起点以前历史的独立编码分支，并检查前缀不变性及 batch 组成敏感性；仅给卷积加掩码仍不足以保证全模块因果。本次不执行该验证。
