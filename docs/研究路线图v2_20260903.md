## 第 2 阶段：G10 受限适配（主实验，预注册冻结如下）

**命题**：A 股本土化需要住进 predictor 的哪个零件？全参数微调（102M 同时学）把 alpha
踩碎在 2000 步；只解锁一个零件（1~3M）能否得到平台化、更稳的本土化版本？

**不变项（逐字复用 G1）**：tokenizer = G1 微调版（冻结）；语料全 A 2014-2024；
val 2025H1；epochs=15、lr 4e-5（四臂统一，LoRA 不单调——单变量纪律，欠训风险如实披露）、
batch 50、每 epoch 2000 步；**保存全部 epoch**；canonical 推理与引擎；csi300。

**起点**：官方 predictor + G1 tokenizer（= G9 的 E0，−11.63%，零点锚）。

**臂（冻结）**：

| 臂 | 解锁 | 可训参数 | 假说 |
|---|---|---|---|
| A0 | 全参数（对照 + D3 亚 epoch 曲线） | 102M | 复现 G1 的刀锋形态 |
| A1 | DualHead（粗头+细头） | 1.7M | 本土化 = 重校"词→概率"的出口 |
| A2 | DependencyAwareLayer | 2.8M | 本土化 = 重学粗→细条件结构 |
| A3 | HierarchicalEmbedding | 3.1M | 本土化 = 重学词的表征 |
| A4 | 12 层注意力 q/k/v/o 各加 LoRA(r=8)，其余冻结 | 0.64M | 语法要动，但只准沿低秩方向 |

其它零件一律"照常使用、权重不更新"。

**评估**：每臂取 best-CE checkpoint 与 epoch-15 两点，backtest 窗（2026-01-01~2026-07-24）
四变体推理；2025H2 对本轮合法（val 仍为 2025H1），过存活线者补跑。

**判据（冻结）**：

| # | 判据 | 定义 |
|---|---|---|
| Q0 复现锚 | A0 best 点等权 AER 与 G1 s100 +14.33% 差 ≤ 1pp | 管线无误 |
| Q1 存活 | 某臂 best 点双基准 AER > 0 | 该零件足以承载本土化 |
| **Q2 平台（核心）** | 存活臂的 epoch-15 点仍 > 0 且与自身 best 点差在 ±26pp 内 | 受限适配的最优点是平台而非刀锋——可直接改写再训协议 |
| Q3 对在位者 | 配对差 vs G1 s100；带内只许方向性描述；> +26pp 才许"显著更好" | — |
| Q4 关闭 | A1~A4 best 点全 ≤ 0 | "受限适配不足以本土化，A 股需要全参数的 2000 步"；不做秩/lr 搜索 |
| 两阶段 | 过 Q1 者补 seed 101/102 确认（夜 2）；未过者不补 | 种子教训 |

**结局地图**：A1/A3 活 → 本土化是词汇级，语法不用动（最精悍的 G1 替代品）；A4 活而 A1-A3 死 → 语法需动但低秩即可（LoRA 进再训协议）；全死 → 全参数 2000 步是必要形态，G1 的刀锋是真相；任一臂 epoch-15 仍活 → 第一次得到"不怕多训"的本土化版本。

**预算**：夜 1 = 五臂训练（A0 ~45min，A1-A4 各 ~30-45min）+ 10 组推理 ≈ 12h；
夜 2 = 种子确认（视 Q1 结果）。
