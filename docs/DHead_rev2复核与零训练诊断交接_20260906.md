## 2. 为什么先做零训练诊断

仿射输出为r_hat=a*z_hat+b，b=(90日mean_close-close_t)/close_t。
即使z_hat恒为0，输出也已经是逐股变化的“90日均价相对现价”信号。原对照只有全局均值，无法分离接口引入的确定性信号和训练学到的增量。

因此本轮只回答：B相比**自身未训练头**和**z=0的仿射基线**到底新增了多少教师拟合能力。此问题不需要改epoch、学习率、N或样本，也不使用新行情。

## 3. 冻结的诊断口径

数据严格使用rev2的相同8日/512样本、相同scale、相同eval教师replica0/1/2。只读既有资产，校验manifest/checkpoint内容和历史代码版本。

按日等权列出以下六个预测器，预测尺度统一为原始收益率：

| 预测器 | 定义 |
|---|---|
| G | 原报告的全局逐期限均值，只从8日replica0计算 |
| Z | 恒零收益，作为价格持平参照 |
| B0 | 标准化close预测恒0，收益=a*0+b，即每个horizon均为b |
| B_init | seed42、与原B完全相同的初始化权重，无梯度步 |
| B_final | 原B第199 epoch checkpoint（200个epoch的末点） |
| A_final | 原A第199 epoch checkpoint |

- 对每个预测器输出D(vs r0)、E1(vs r1)、E2(vs r2)、对r0/r1/r2的逐日Spearman与有效日数、学生截面方差。常量零方差相关记NA，不能记成有效0。
- 报告逐日明细、8日等权汇总，以及B_final−B_init、B_final−B0的配对误差差值；误差负差表示改善。此为事后描述，不追加显著性检验或选择阈值。
- B_init在不加载旧checkpoint的情况下重建，初始化模块顺序与e5f10c3保持一致；报告state_dict hash。训练过的B_final不能用来初始化B_init。
- R_train照原报告由同日r1/r2计算；不把sqrt(R_train)当单replica噪声；不同窗口的R不相减做dropout贡献。
- 不调用trainer.fit，不重建teacher目标，不更改或删除既有run。需要模型前向时只用inference/eval，既有研究GPU累计至多10分钟，按既有登记时段让出GPU。

允许的描述：若B_final较B_init/B0误差更低且排序改善，可记录“在已训练的8日样本上有训练增量”；若没有，则记录“目前改善主要与输出接口/确定性基线相容”。无论哪种都不能推出样本外有效、容量不足、需要扩大训练或main解锁。

## 4. 同步修正两个实现与报告边界

### 4.1 运行目录与恢复身份

minimal_fit.py:198的训练目录固定为v11rev2-A/B-s42，不含namespace，而summary目录含namespace。不同namespace运行会重用训练目录、拒绝或意外恢复，不能把它描述成完全隔离。

- 未来新run的A/B目录包含namespace和run身份；默认已存在目录只允许明确的只读复核，不自动调用fit继续训练。
- 保留原目录原样。诊断入口支持显式历史run路径，严格核验它属于e5f10c3实验manifest；新诊断代码hash和历史训练代码hash分别记录，不篡改原checkpoint身份。
- 新增离线测试：两个namespace不共享学生目录；已完成run不会被诊断命令再次优化；保存前后checkpoint hash一致。

### 4.2 门禁身份核验

- main门禁必须绑定明确pilot run：teacher/schema/namespace、输出语义、种子、权重/清单内容/选中checkpoint hash、scale、评价代码版本。pilot和main样本预算不同，不能直接要求两者完整protocol hash相同；检查预声明的允许差异并记录映射。
- D2门禁不能只检查summary存在及其中的身份文字。加载当前前置result与selected checkpoint实际hash，和fidelity summary绑定值比较；更换checkpoint或weight后，旧PASS不能继续解锁。
- 补离线反例：旧PASS在权重或选中checkpoint改变后应拒绝；不同namespace/schema的pilot PASS不可混用；本次既有FAIL仍拒绝扩大。
- 如完整门禁仍未实现，直接保持相关命令锁定并标记未完成，不以部分修复宣称闭环。该工作不妨碍零训练诊断。

### 4.3 文档与耗时口径

- 将“显著优于A”改为“本批样本数值优于A”，因为没有统计检验。
- 将“无逐股方差/排序证据”改为“观察到训练样本排序相关，但尚不能确认相对接口基线的训练增量与泛化”。冻结FAIL原样保留。
