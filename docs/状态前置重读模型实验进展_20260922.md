## 4. 两处官方口径发现（重要披露）

1. **官方推理路径从不调用 `model.eval()`**：`KronosPredictor` 构造（model/kronos.py:482）只做 `.to(device)`；Kronos-base 的 `ffn_dropout_p=resid_dropout_p=0.2` 在官方全部推理（含 F0 parquet 生成）中生效。处理：canonical B0 直接只读既有 parquet（不受影响）；TAS/B1 生成底座恒 eval（确定性 + 复现门禁）；P0 对拍时原调用临时 eval 以获得确定性判定。B1 重跑采用官方原路径口径（`KronosPredictor`，不 eval），在结果文档再次披露。
2. **原版 `decode_s2` 自回归的 RoPE 退化**：生成时 q_len=1，`RotaryPositionalEmbedding.forward` 的 cache 长度取 q.shape[-2]，query 与全部 key 均按位置 0 旋转（无相对位置）；而官方微调训练时 dep_layer 为方形（q=k=L，正常位置）。该训练/生成不一致是原设计的一部分。处理：TAS 自由生成的 s2 直接调用原版 `decode_s2`（与 B0 同数值路径）；训练/teacher forcing 用显式因果方形实现（与官方训练路径逐位一致，测试锁定）。
