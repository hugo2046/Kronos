## 1. Canonical Baseline 定义（本计划的核心产出，定死后不再动）

- **模型**：Kronos-base（zero-shot，官方权重，不微调）；
- **信号族**：四变体，**全部除以现价**（修正上游 demo 的价格尺度偏差）：
  - `last = pred_close[t+H]/close_t − 1`
  - `mean = mean(pred_close[t+1..t+H])/close_t − 1`（**canonical 主线 = 已有 K 组，不重算**）
  - `max = max(...)/close_t − 1`
  - `min = min(...)/close_t − 1`
- **推理**：N=20，`T=1.0, top_p=0.9, top_k=0`，seed=42，L=90/H=10；
- **组合**：`paper_replication/engine.py`，k=50 / n=5 / min_hold=5 / 单边 15bp，csi300 point-in-time；
- **双基准**：`000300.SH` 指数（对外口径）+ 同池等权（选股 alpha / 门禁）；
- **窗口**：论文窗口 2024-07-01~2025-06-30；
- **呈现**：图1 同款双图（累计收益含成本 + 累计超额，四变体 + CSI300 虚线）+ 双基准指标表。

**canonical 主线永远是 mean**（论文公式），无论四变体谁强——min 若显著更强，作为
探索性发现单独记录（§5.3），不得事后改 canonical。

## 3. 阶段 2：KDA 三臂 long-only 重评（对照记录，无翻案门槛）

1. 载入 `{B1,B2,B3}_best.pt` 冻结 checkpoint，对论文窗口每个交易日出截面得分
   （输入口径与训练一致：窗口 z-score+clip5；B2/B3 经冻结 Kronos 主干取隐状态）；
2. 同引擎同双基准回测，与 baseline 四变体同表呈现；
3. **预注册立场**：这是**换评估口径的补测**（多空 → long-only），不是翻案。三臂的
   RankIC（0.0075 以下）预期跑不过 baseline mean；结果无论好坏只做记录，
   不触发任何重训/调参。若某臂意外超过 baseline mean，标注"待样本外验证"而非"有效"。

## 4. 阶段 3：真样本外延展（本轮最重要的判定）

- **窗口**：2025-07-01 ~ 2026-07-31（论文没见过、我们所有调参也没碰过的一年）；
  运行前断言窗口末日 + 结算余量 ≤ 数据末日 2026-08-07；
- **对象**：baseline 四变体（重推理约 2.2 小时）+ M/R/P 三条对照（动量/反转/占位，引擎零点
  在新窗口顺带复验：P 组 AER(等权) 仍须 < +3%）；
- KDA 三臂同窗推理成本极低，一并跑（同 §3 的记录立场）；
- **预注册判定（跑之前冻结）**：
  1. 主判据：baseline **mean** 样本外 `AER(等权) > 0` **且** `AER(指数) > 0` → "正超额在样本外成立"；
  2. IR(指数) ≥ 0.3 → 附注"强度未塌方"；< 0.3 但 AER>0 → "方向存活、强度衰减"；
  3. mean 样本外 AER(等权) ≤ 0 → "论文窗口的正结果不能外推，疑似窗口运气"，如实记录，
     **不做任何参数搜索**；
  4. min 变体：若论文窗口与样本外**两段都**显著强于 mean（AER(等权) 差 > 3pp），
     记录为"预测路径下界含风险信息"的候选发现，留待下一轮独立立项验证，本轮不改 canonical。
