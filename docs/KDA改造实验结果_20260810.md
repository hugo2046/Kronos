## 4. 判定（预注册，计划 §0 归因逻辑）

### 4.1 主判定（预注册）

> `RankIC(B3) > RankIC(B0=+0.0185)` **且** `RankIC(B3) > RankIC(B1)` → 改造有效

- B3 RankIC = +0.0075，**B0 = +0.0185** → B3 **未**超过 B0（差 -0.0110）；
- 即便 B3 > B1（+0.0075 > -0.0161），主判定的"且"条件仍不满足。

**判定：改造未达预注册有效门槛（B3 未超过论文原版信号 B0）。** 按 §5 纪律封盘，不回头调参。

### 4.2 次要归因

| 归因问题 | 实测 | 结论 |
|---|---|---|
| 改造有效？(B3>B0 且 B3>B1) | B3=0.0075 < B0=0.0185；B3>B1 | ❌ 不成立（未超 B0） |
| KDA 头有独立贡献？(B3>B2) | B3=0.0075 > B2=-0.0008 | ✅ 成立（但两人都在零附近，统计意义弱） |
| 增益来自预训练表示？(B3 vs B2) | final 段 B3≈B2≈0 | 无法分辨（样本外都退化） |

**关键发现：早停段与最终验证段的巨大落差**——B2 早停段 RankIC +0.114 / ICIR 0.721（t=7.46，
看似极强），到 final 段跌到 -0.001；B1/B3 同样从 +0.108/+0.076 跌到 -0.016/+0.007。
这是典型的**样本内过拟合、样本外失效**：14 万训练样本对 2022-2023 的市场 regime 学到了
不能外推到 2024-07 之后（预训练截止之后、风格切换）的模式。

## 5. 计划偏差与局限

### 5.1 实施中的必要偏差（均已如实记录）

1. **batch size 1024 → 128**：计划 §2 预注册 batch=1024，但 d_model=832 下 KDA 递归状态
   `[B, H, K, V]` 在 batch=256 即 OOM（RTX 5090 32GB，峰值 19.6GB @ 128）。落到硬件上限 128，
   属硬件必要偏差（batch 仍是 2 的幂、训练动态同量级）。**超参调整只在训练/早停段内做，final 段一次定型。**

2. **参数量与计划粗估**：计划 §0 表格写 B1"~0.1M"、B3"~1M"，实测 d_model=832 下
   B1=14.6M、B3 头=15.3M（`gate_rank=d/nhead=104` 使遗忘门/输出门投影满维，单 KDA block
   ~7.3M）。B2 probe=833（~0.8K，与计划一致）。**B1/B3 头同结构、唯一变量是预训练表示，
   对照纯度不受影响**；但 B3 参数量大是其易过拟合的因素之一。

### 5.2 局限性（写全）

- **早停段过拟合**（核心局限）：B1/B2/B3 早停段 RankIC 0.08~0.11、t 3~7，但 final 段全部
  跌到零附近。14 万样本、~15M 参数的 KDA 头在 2022-2023 学到的模式不能外推到 2024-07 之后。
  这本身就是一条有价值的结论——**表示学习的红利在样本内，样本外被 regime 切换磨平**。
- **五臂 final 段全部弱**：同期 B0 也仅 +0.0185 / |ICIR| 0.105（低于 0.02/0.3 门槛），
  说明 2024-07~2026-07 这段 csi300 短周期截面信号普遍失效，不是改造单独的问题。
- **单池 / 单区间 / 单切分**：结论严格针对 csi300 / 2022-01~2026-07 / 日频 H=10 / 5 分组多空；
  不外推到其它池、其它频段或更长/更短样本。
- **ST 未剔除、可交易性未建模、停牌股整只剔除的轻微选择性**：沿用 zero-shot 测试的口径（见
  [截面路径zero-shot测试结果_20260810.md](./截面路径zero-shot测试结果_20260810.md) §5）。
- **KDA 递归未做并行化**：90 步 Python 循环使 B3 每 epoch ~295s；改用 chunk 并行会更快但不改结论。
- **结果绑定 DDB 实例 `100.**.**.25:8848` 与数据末日 2026-08-07**；后复权口径、
  `tradestatuscode` 语义均绑定该实例。

## 7. 下一步建议

1. **本结论的适用边界**：仅对本实验口径成立——Kronos-**base** / batch 128 / 2022-01~2026-07 /
   每日采样 / 截面 z-score 标签 / 5 分组多空。**不得据本文档断言"KDA 头对 Kronos 无价值"**，
   只能说"本口径下未通过预注册门槛"。
2. **过拟合是主因**：早停段 vs final 段的巨大落差指向样本内过拟合。可能的改进方向（**另立计划，
   不在本轮封盘后偷偷做**）：更强的正则（dropout / weight decay 加大）、更小头（降 d_model 瓶颈）、
   更短训练（epoch 1 即最佳，可考虑单 epoch + 更大 batch 的 SGD）、跨 regime 验证。
3. **B0 在论文窗口仍最强**：监督训练没把 zero-shot 的边际优势放大。若目标是复现论文 AER/IR，
   应先按论文口径（large 模型 / N=20 采样 / 每日调仓 / long-only top-50）跑 zero-shot，
   而非继续在 base 上加监督头（见 zero-shot 测试文档 §7 的 P0 复现建议）。
4. **B4 不做**：计划标注"可选，B3 达标后才做"，B3 未达标，故不做。
