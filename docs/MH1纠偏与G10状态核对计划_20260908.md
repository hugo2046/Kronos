## 5. 任务 C：毛收益、成本、净收益同路径分解

本轮诊断只改变是否扣除已发生的费用，不改变持仓、成交、日期、信号或策略参数。

从**同一次收费 v2 运行**的交易日志重建：

```python
trade_frame = trades.to_frame()
daily_cost = (
    trade_frame.groupby("date")["cost"].sum()
    .reindex(net.index, fill_value=0.0)
)
gross = net + daily_cost
gross_nav = (1.0 + gross).cumprod()
net_nav = (1.0 + net).cumprod()
nav_drag = gross_nav - net_nav
```

这里 gross 是同一已成交路径的费用加回结果，不是取消涨跌停、延迟或持仓限制的理想化策略。不得用“成本求和”直接代替复利净值差，也不得对不同路径 AER 相减后宣称纯成本贡献。

- [ ] 导出逐日 `gross_return/net_return/cost/gross_nav/net_nav/turnover_one_side/turnover_double` 及两基准收益；原始交易日志保留 decision_date、成交日、卖出/买入名单与金额。
- [ ] 每天验证 `net = gross - cost`（绝对误差≤1e-12）和 `cost=(freed+bought_amt)*0.0015`；人工 100% 卖出再 100% 买入应扣 0.003，初始仅买入 100% 应扣 0.0015。
- [ ] 毛/净两个策略自身净值分别算累计收益、年化收益和最大回撤；双基准 AER/IR 使用 v2 接口。明确区分“策略自身最大回撤”和“超额净值最大回撤”，不将超额亏损说成绝对亏损。
- [ ] 同一臂同一窗口毛/净超额评价必须采用相同有效日期；报告 `sum(cost)`、复利净值拖累、毛/净双基准指标及交易天数。成本值大不等于已证明它是表现弱的唯一原因。
