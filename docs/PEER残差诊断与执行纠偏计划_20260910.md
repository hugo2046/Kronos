### 4.1 冻结计算公式

每个日期只在原 SAE 64 个监督格计算，整个 PeerSet 仍参与 ON/OFF forward。不能把额外 peer 的零填充目标纳入 MSE，也不能缩为 64 股 attention context。

设 `e = y_mean - s_G1`，`r = e / sigma_e`，`r_hat_G1 = 0`，`s_arm = s_G1 + sigma_e * r_hat_arm`。不减残差均值，不增加校准或缩放。

```python
def day_errors(r: np.ndarray, r_hat: np.ndarray,
               sigma_e: float) -> dict[str, float]:
    error = r - r_hat  # 参数已截取当日 LossSet
    mse_norm = float(np.mean(error ** 2))
    return {"mse_norm": mse_norm,
            "mse_return": mse_norm * sigma_e ** 2,
            "bias_return": float(np.mean(error)) * sigma_e}

# 各日期已经对 64 个监督格求均值，再跨日期等权。
summary = daily.groupby(["split", "arm"])[
    ["mse_norm", "mse_return", "bias_return"]
].mean()
```
