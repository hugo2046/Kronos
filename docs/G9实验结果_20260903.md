## 0. 一句话结论

**K2 两窗配对差均 < 0 → CE 早停正确，过拟合墙为真。** 训满 15 epoch 的
predictor（E15，唯一预声明对照臂）在两窗全部塌方（backtest AER 等权
−2.19% vs E1 +14.33%；2025H2 −2.90% vs E1 +5.95%），且 alpha 在 epoch 1
之后立刻消失（E5/E10 描述性曲线同样为负）。CE 早停规则（epoch 1 即停）
**不是**保守偷懒——它恰好停在唯一有 alpha 的位置上。K0 完美复现
（+0.0044pp）：同 seed 重训的下游推理-引擎链路逐位复现在位者。议题不关闭
（K4 未触发：配对差 −16.5pp 在 ±26pp 噪声带内，未达"显著更差"强措辞门槛），
但"训满 checkpoint 为候选"路径被否定，计划 §3 三种子确认**不触发**。

## 3. K0~K4 + E0 一次封盘判读（定义 = 计划 §2 跑前冻结）

- **[K0 复现锚] PASS**：E1 backtest AER(等权) **+14.33%** vs 冻结锚
  +14.33%（G1_mean，20260815 结果文档）差 **+0.0044pp** ≤ 1pp → 重训复现
  在位者（训练 CE 逐位一致 + 下游推理-引擎逐位复现），配对基线 = E1。
- **[K1 存活] FAIL**：E15 backtest AER(等权) −2.19%、AER(指数) −6.20%，
  双基准均 ≤ 0 → 存活判据未过。
- **[K2 方向（核心决策规则）] 负向**：配对差 (E15 − E1)：backtest
  **−16.53pp**、2025H2 **−8.85pp**，两窗均 < 0 → **"CE 早停正确，过拟合
  墙为真"**。§3 三种子确认不触发；再训协议不修订；学习率/步数实验永不。
- **[K3 显著] 带内**：max |E15−E1| = 16.53pp ≤ 26pp → 只许方向性描述
  （"E15 方向性差于 E1"，不得使用"显著更好/更差"强措辞）。
- **[K4 关闭] 未触发**：E15 双基准 ≤ 0 满足，但 backtest 配对差 −16.53pp
  未越 −26pp → 议题不关闭（选择规则问题保持"已检验、当前规则正确"状态，
  非永久关闭）。
- **[E0 判读（仅描述）]**：E0 −11.63% 与 E1 +14.33% 差 **−25.97pp**，落
  在 26pp 噪声带内但**贴带边**（margin 0.03pp）→ 按冻结规则记录机制线索
  "alpha 主要由 tokenizer 承载"；同时如实并记：E0 深负于 E1 的方向亦与
  predictor 适配贡献相容（E0 − G1 tokenizer 组合较 F0_mean −17.23% 改善
  +5.6pp = tokenizer 单独贡献的下界线索；E1 再 +25.97pp = predictor 2000
  步贡献），单种子不可分离，仅供参考。
- **epoch 曲线（描述性，不进判据）**：E1 +14.33% → E5 −2.09% → E10 −2.06%
  → E15 −2.19%——alpha 在 epoch 1 后**立即**消失并归零平台，非渐变衰减。
