## 2. 阶段 1：组合引擎（新增的唯一模块）

新代码入 `paper_replication/`，核心是 top-k/drop-n 组合引擎（这是与既有 `cross_section/`
评估的本质区别——那边是分组多空，这边是论文的 long-only 规则）：

### 2.1 引擎规则（严格按东证/论文描述，见 notebooklm 问答 Q1/Q6）

- 每个交易日 t 收盘：按当日信号对池内可用股票排序；
- 目标持仓 k=50 等权；**每日最大调入/调出 n=5 只**；
- **最少持有期 5 个交易日**：持有不满 5 日的股票不得卖出（即便信号变差）；
- 卖出候选 = 持有≥5日 且 信号排名最差者；买入候选 = 未持有 且 信号排名最好者；
  每日实际换手 = min(n, 可卖数, 可买数)；
- 交易成本：单边 0.15%，按换手额从组合收益中扣除；
- 停牌股：当日不可买卖（沿用 `tradestatuscode==0` 判定），持仓中停牌的顺延；
- 初始建仓：首日按信号 top-50 一次建满（论文未述，属实现假设，记录之）。

### 2.2 引擎单测（先于任何真实信号）

1. 最少持有期约束：构造信号翻转用例，持有 <5 日的股票必须没被卖出；
2. drop-n 约束：单日换手不超过 n；
3. 等权再平衡口径：明确并测试（建议：只在调入调出时再平衡新腿，存量腿随行就市——
   实现方选定后写进文档，前后一致即可）；
4. 成本扣除：给定换手额，净值扣减精确可算；
5. **占位信号回归**：用 seed 固定的随机信号跑引擎，AER 应≈0（|AER|<3%）——
   证明引擎本身不制造 alpha（这是本阶段最重要的一道门禁）。

### 2.3 基准探测

- 先探测 DDB 是否有沪深300 指数行情（如 `000300.SH` / 独立指数表）；有则用指数日收益算超额；
- 没有则用**当日 point-in-time csi300 池等权收益**作基准，并在结果文档显著标注
  "基准为等权池而非市值加权指数"（等权基准通常更强，会**压低** AER，属保守偏差）。

## 3. 阶段 2：信号生成（复用为主）

- 复用 `kronos_qlib.build_inference_windows` + `KronosPredictor.predict_batch`；
- 区间 2024-07-01~2025-06-30 每个交易日（约 240 个），`sample_count=20`，
  `T=1.0, top_p=0.9, top_k=0`，`torch.manual_seed(42)`；
- 计时参考：N=5 时全池 8.1s/日 → N=20 约 32s/日 × 240 日 ≈ **2.2 小时**，可断点续跑；
- **N 敏感性试点**（先做）：取 1 个月（约 21 日）分别跑 N=5 与 N=20，对比信号截面相关与
  日均 RankIC——论文声称随 N 单调改善，若 N=20 反而更差，先停下排查再全量；
- 产出 `paper_replication/data/daily_signals.parquet`（`date, code, signal`，不入库）。

## 4. 阶段 3：回测与判读（预注册）

**同一引擎跑四组信号**（这是控制变量的关键，缺一组不得下结论）：

| 组 | 信号 | 作用 |
|---|---|---|
| K | Kronos-base，N=20 | 被试 |
| M | 10 日动量 | 免费基线 |
| R | 10 日反转 | 免费基线 |
| P | 随机占位（seed=42） | 引擎零点 |

指标：AER（年化超额，扣成本）、IR（超额日收益均值/std×√252）、最大回撤、日均换手。

**判读（按顺序）**：

1. **引擎门禁**：P 组 |AER| ≥ 3% → 引擎有 bug，停止，不看其余结果；
2. **锚点比较（若阶段 0 拿到 base 锚点）**：K 组 AER/IR 与论文 base 规格数字同量级
   （AER 差距 < 10 个百分点且同号）→ **复现成功**；
3. **定性判定（无锚点时）**：K 组 AER > 0 且 IR > 0.5 且 K 组 AER/IR 均高于 M、R 两组 →
   "论文方向可复现（base 规格）"；K 组 ≤ 0 或不敌免费基线 → "论文结果在本数据上不可复现"，
   如实记录，**不做参数搜索**；
4. 无论结果如何，与此前 10 日调仓口径的 RankIC 结果（同区间 B0 +0.0389）互为印证写入文档：
   每日调仓 + top-50 是否把截面排序的微弱优势转化成了组合收益，本身就是核心发现。
