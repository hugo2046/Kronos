### 6.1 均值基线诊断（val 分片，不触回放收益）

| 预测器 | E（scale 归一，按日等权） |
|---|---|
| 全局均值（训练教师目标均值） | 0.0621 |
| **日内均值（每天教师截面均值）** | **0.0469** |
| 训练后的 D0 | 0.1082 |
| 教师 replica 噪声 R | 0.0220 |

解读：训练后的 D0 **劣于"每天只预测教师截面均值"的平凡基线**，且
Spearman≈0.036 —— 学生在 pilot 预算（4,096 样本/64 日）下只学到均值水平，
未学到任何逐股教师信号；教师 N=20 平均后的截面信号 std（scale 单位）≈0.186，
自身 replica 噪声 ≈0.148，信噪比本身偏薄。该诊断不改变冻结判定，只作解释。

## 11. 结论

1. **工程出口：本规格未通过**（pilot 口径）。D0 在 pilot 预算下未逼近教师
   （劣于日内均值基线），保真两条件均未达阈值；按预注册规则 main/D1/D2
   全部停止。依据 §8.1"pilot/model 不足不产生'架构无效'结论"——本结果
   不支持"读出架构/蒸馏路线已被穷尽"的更强表述；教师 replica 噪声与截面
   信号同量级这一实测，提示该教师在其 N=20 协议下可供蒸馏的截面信息有限。
2. **研究出口：未开考**。经济回放未运行（引擎复核未做 + 上游门禁未过），
   无任何收益结论；S 直接监督结果保留于 pilot 规模（val_s 0.4672 /
   val_i 0.9488），不构成 alpha 证据。
3. 复用资产：全部代码、测试、清单与教师分片可复现；若另立方案重开
   （例如加大 pilot 样本/epoch、提高教师 N、换 loss 尺度），须新预注册，
   不得在本 run 目录混写。
