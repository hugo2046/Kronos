# D组合风险约束独立实现审查

协调器已读risk_overlay.py初版。新风险收益执行前优先处理前两项，保持原冻结规则，不改参数。

1. generate_trade_decision第一天：原super在前一日无信号时会返回空决策，但non-neutral仍无条件risk_panel.xs(t)。面板只含冻结信号日期时，W3首日t=2025-06-30/W4首日t=2025-12-31不在面板，会KeyError。需区分无前日有效信号/无可用panel的首日，保持原策略不下单；按真实交易日历加首日回归门禁，不能平移信号解决。
2. build_risk_panel把所有不在当日D有效信号池的股票factor强制设0.5且missing_risk=True，这超出了冻结规则。有效信号池仅用于计算median_sigma；已持有但暂时退出信号池的股票只要有合法60日sigma，就应使用同一median计算其真实f。只有风险历史不足才fallback0.5，不能把缺信号当缺风险，避免额外的隐含退出惩罚。请加已持有/不在当日有效池但sigma有效的情形验证。
3. last_history_date需与price使用的valid正有限价格mask一致，当前close.notna包含inf/非正值，元数据与实际ffill估值可能不一致。保证price来源日期<=决策日。
4. RiskOverlayStrategy.__init__和类docstring按用户Sphinx规范补齐参数/返回值及->None；这不改变行为。移除build_risk_panel未使用的factor局部变量，保持最小变更。
5. cap_vol的实际基础上限为3%×f，即1.5%至3%，报告不能写成统一3%硬上限；风险额外卖单和后续现金路径导致持仓选择也可能变化，应保留明确边界。

所有处置记录在报告。若尚未跑收益，修复作为实施更正不改原协议；若已经跑过需要记录、重新做neutral及固定配置回测，不能挑选前后更好的结果。
