## 固定边界与工程落实

实现`g1_timesblock`，仅复用state_adapter受审有界SQL、隔离账户和原生Kronos生成接口。无旧tau模块导入，无风险头模块导入，无共享quant-qlib源码修改。本轮OUT是`artifacts/experiments/g1_timesblock_20261117`。

归一化逐样本从`DataFrame.copy()`再选择六列取得float32数组，保留原生布局和axis0归约顺序。合成测试拦截真实`KronosPredictor.predict_batch`的generate输入并逐值核验，不能用C布局batch归约代替。

tokenizer始终encode前缀90..100，核验全部位置的一致性。安全fallback固定发行时90个历史token，只追加每个成熟日prefix编码末位token；监督目标也为对应prefix末位，不重编码已发行历史。该修订避免非因果tokenizer未来扰动覆盖旧token；不依据预测效果选择路径。

每步原生decode_s1/decode_s2，仅将当时可见token传给细头。新增残差在`set_history`时计算一次并保留反向图，十步内固定，只加最后norm位置。预测stock-first展开20条路径。分支逐样本频率，按相同周期分组计算；幅度仍各样本独立。稳定降序选频等幅取小频率。官方批均选频改为逐样本是预登记差异。

共享结构和对应卷积flatten初始化相同。训练粗头有独立torch.Generator seed100，不消耗验证流；恢复同时保存optimizer、CPU/CUDA/NumPy/Python全局RNG、粗头独立RNG及窗口采样器。窗口批次SHA在两臂共享的batch_sequence中只写一次，不同序列立即拒绝。

## 独立进程入口

先完成独立代码审查，再由root执行真实准备和签字。所有命令使用quant Python，不动态安装包。

1. `python -m g1_timesblock.pipeline prepare`：读取日历元数据，固定历史资产、官方源码和协议SHA；不加载真实模型。此阶段会初始化只读提供器，必须由root执行，本工程实施未执行。
2. root签`OUT/review_gate.json`：`approved=true`、`reviewer=root`、`protocol_sha=runtime.identity(p)`、`source_hashes=runtime.sources()`，必须审查当前固定commit。
3. `python -m g1_timesblock.pipeline pilot`：原始全网格、2048验证tokens、两臂零残差对拍、first/middle/last日期双流保真、两臂实际step64/完整验证/截面成本及完整恢复。生成A_model，禁止自签。
4. `python -m g1_timesblock.pipeline accounts-baseline`：三个冻结参照重新跑纠偏账户，原G1及MC40与固定旧账逐业务键按字段对账（业务原值exact；指定聚合率绝对容差1e-12、现金/NAV绝对容差1e-6元，rtol=0）；首次完成后A_accounts绑定全部参照信号/账户/身份文件SHA和实测耗时。再次执行或由all调用时，核验身份、完整文件集与内容（已有A_gate时还核验原签字），只读复用，不重写证据字节或首次耗时。
5. root签`OUT/A_gate.json`：`passed=true`、`reviewer=root`、`identity=train.training_identity(p)`、`evidence_sha`至少包括`A_model.json`、`A_accounts.json`、`input_grid.json`的当前SHA。训练前计入账户实测耗时再次检验预算。
6. `python -m g1_timesblock.pipeline all`：顺序以独立进程执行两臂训练、完整两窗双流推理、五对象账户、2048及12日机制诊断、真实图表与中文报告。已有有效A_model复用；未签A_gate则停止等待root，不自签。也可分别运行`train-temporal`、`train-timesblock`、`infer-temporal`、`infer-timesblock`、`accounts`、`diagnostics`、`report`。

GPU12h/墙钟16h从首次模型计算累计，加载、分词、验证、失败恢复、推理和诊断均计费。A估算覆盖6000更新、两臂各7次验证及三对象诊断验证、1040日期流、36个诊断截面、后续7次模型加载、25%失败余量及报告/账户余量；不满足即停。16:25—16:45守卫保留。pipeline锁防重复调度，worker锁防并发计算。
