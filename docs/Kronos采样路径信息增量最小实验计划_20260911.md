# Kronos 采样路径信息增量最小实验计划（20260911）

> 执行者：Debian zcode，使用 executing-plans 技能逐项执行。用户批准先验证路径集合相对 mean 是否有额外信息；本轮不加入门控或 TimesFM，不启动策略回测或独立 forward 验证。

**目标：** 在冻结项目 G1 的条件下，用一个小型路径集合读出器，检验采样路径的形状与分歧能否在 mean 之外改善截面排序。

**架构：** 保留 G1 的20条未来10日采样路径，去掉新采样整体均值，仅将路径形状提供给一个753参数的集合小头；对照小头结构相同但路径输入全零。二者都对原 G1 mean 加残差。

**技术栈：** Python 3.10+、PyTorch、numpy/pandas、pathlib、loguru；Qlib仅用于有日期边界的历史数据提取，统计诊断与小头训练走 CPU。

## 4. 任务一：检查路径是否已保存，正确打开样本维出口

**拟修改：** `model/kronos.py`；**新增：** `path_information/paths.py`、`tests/test_path_information.py`。只做向后兼容的可选路径出口，不改默认推理。

当前源码 `auto_regressive_inference` 末尾为：

```python
z = z.reshape(-1, sample_count, z.size(1), z.size(2))
preds = z.cpu().numpy()
preds = np.mean(preds, axis=1)
```

因此旧 mean、每期限mean路径、SAE末步h均不能重建20条样本。preflight只查缓存schema与历史文件身份；只有保留样本轴、维度/来源/采样参数完整且匹配本协议的文件可复用。不能把均值复制20次冒充原始路径。

- [ ] 先写失败测试：可选 `return_samples=True` 时应返回 `[B,N,H,6]`；默认仍是原 `[B,H,6]` 数值与旧 `predict_batch` 返回类型。
- [ ] `auto_regressive_inference` / `generate` / `predict_batch` 透传 `return_samples=False`。默认分支保留原平均和反归一化顺序；样本分支保留N，未来切片使用最后两个轴，逐股票使用历史窗口统计反归一化，不能错把N当时间轴。
- [ ] 样本分支输出真实价格维的20×10 close路径；输入窗口标准化继续使用原代码的float32 z-score、clip5，未来数据不参与统计。
- [ ] 同一合成tokenizer/model、同输入与完整RNG起点，对照旧源版本与默认分支：输出和结束RNG一致。样本分支归一化空间均值与旧平均输出一致；反归一化价格采用 `rtol=1e-6, atol=1e-5`，顺序舍入差如实披露，不能调宽容差。
- [ ] 不是调用20次独立 `sample_count=1`：这会改变批次和随机流，不是同一个 N=20 实现。
- [ ] 固定推理 L90/H10/N20、T1.0/top_p0.9/top_k0、max_context512、clip5，FP32、chunk32；每个日期开始seed42（Python/numpy/TorchCPU/CUDA均记录），两chunk按code顺序共享该日流。断点只在完整日边界复用，失败部分不混入完成缓存。
- [ ] 新生成路径属于新采样链；记录新路径均值与原G1 mean之差，但不替换基线、不要求与旧legacy生成链逐位一致、不称差值为已估计的“采样噪声带”。

## 5. 任务二：只保留形状增量，固定两个同构小头

**新增：** `path_information/model.py`、`path_information/train.py`。

真实价格样本转为相对当前close的未来路径收益 `p[n,h]=close_pred[n,h]/close_t-1`。定义：

```python
# p: [B,20,10]，B是股票样本，不在股票间交换信息。
shape = p - p.mean(axis=(-2, -1), keepdims=True)
b = (s_g1_original - mu_g1_train) / sigma_g1_train
x_path = shape / sigma_e_train
x_mean = np.zeros_like(x_path)
# 两臂均：s_final = s_g1_original + sigma_e_train * r_hat
```

`mu_g1_train/sigma_g1_train` 与 `sigma_e_train=std(y_mean-s_G1)` 仅用本轮train有效标签格计算，ddof0，冻结后val/dev_eval不重拟合；标准差为零则停止。

共同结构（共753参数，不搜索宽度）：

```text
每条10维路径 → Linear(10,16) → GELU → Linear(16,16) → GELU
20条路径表示等权平均 → 16维
拼接1维b → Linear(17,16) → GELU → Linear(16,1) → r_hat
最后Linear的weight/bias零初始化
```

MEAN喂全零shape，PATH喂真实shape；二者都看到相同原G1 scalar。N轴须排列不变，H轴保留时间次序。MEAN某些输入权重无有效变化，与PATH的有效容量不同需披露；这是信息输入对照，不声称所有有效自由度都相同。

- 固定训练seed100，两臂同初始化哈希、相同日期shuffle和监督格；训练全程CPU、FP32，AdamW lr1e-3/betas(0.9,0.999)/wd0.01，clip_grad_norm3，batch_days4，每日监督股loss均值再对日期等权。
- 目标只用原 mean 标签：`y_mean=mean(close[t+1..t+10])/close_t-1`，`r=(y_mean-s_G1)/sigma_e_train`，损失MSE。沿用同一种误差目标，避免同时换loss无法区分机制。
- 固定50epochs全部训练日期一次遍历/epoch；无scheduler、无早停。将未训练的e0也作为合法候选，按val日等权MSE最低选best，严格更低才更新，并列取更早。选到e0就如实退化为G1，不强迫一个已训练头上场。
- 所有阶段同时报告G1零残差MSE；不能再次只报头的MSE而漏掉原模型。
- 使用独立 `path_information` 协议/缓存/头身份；可借鉴PEER已验收的SHA/不覆盖/legacy隔离模式，不能通过修改PEER全局配置让其冒充PATH1，也不直接依赖PEER固定832维检查。

## 6. 任务三：开封与唯一诊断判据

1. 先冻结协议、代码diff摘要、日期键、基线/权重身份；完成全部路径及train/val标签缓存。

3. 计算三臂逐日相同有效标签格的 Spearman(score,y_mean)，用平均秩，并列/常数日记NaN；配对差使用双方均有效的同一日期集合。输出样本数、有效日数、MSE、日均IC、MEAN−G1、PATH−G1、PATH−MEAN。
4. 唯一“值得另立下一阶段”的开发信号为：**val和dev_eval的日均配对IC差PATH−MEAN均>0，且dev_eval的PATH−G1日均配对IC差>0**。不满足就封存本配置；不自动换loss、加门控、加TimesFM或补种子。
5. 满足也只称“本历史划分下观察到路径信息增量，需另立复验”，不称显著、稳健或已打败G1策略；val参与选点、dev_eval已被历史研究反复观察、预测标签存在10日重叠，都必须披露。
6. 不跑策略回测，不改变原G1交易池，不将64股抽样诊断的RankIC换算为FULL收益。任何后续FULL/Qlib经济对照需新计划，固定原G1主基线及配对新采样mean参照，不能据本轮删尾部的日期直接宣布胜出。

本轮没有推理技巧、门控、TimesFM的附加臂。三臂足以回答当前问题；不得在结果不好后临时增加路径分位数/最大值/风险惩罚等候选。

## 7. 必须先失败后通过的合成契约

- 样本出口维度/真实反归一化/默认返回数值及RNG兼容，N=1退化、B>1不串股；保持原有模型回归测试。
- 改变未来真实价格/标签不改变路径输入、样本键和模型前向；底层feature fetch.end≤t，超封存线在访问数据前拒绝；标签读取与预测provider分离。
- 日期隔离：train/val最后10日标签跨界样本被日历规则排除；不能用stock历史行号替代交易日日历。缺标签只影响共同loss mask，不重新抽股。
- 每个p加任意股票特定常数后shape不变；新采样均值改变不改变原s_G1。MEAN输入不含PATH特征；打乱N轴输出不变；至少存在非零测试权重与非退化路径，使改变shape能改变PATH输出。
- 未训练三臂分数逐值等于原G1；G1零残差MSE手算对拍；统计只用train，改val/dev_eval标签不改变标准化文件。
- 真实生产小头save/load绑定完整身份，错误base/cache/protocol/seed/epoch/文件SHA拒绝；中断产物不自动覆盖，任一复用失败不重训。
- 生产编排用spy锁定：两头dev_eval分数全部落盘、SHA确认后才能调用标签加载与评价；缺一/改一文件，评价调用0次。
- 三臂日期等权、配对有效日、常数日NaN、固定门槛手算对拍。e0最优时真实load_best加载e0，而非最后epoch。
