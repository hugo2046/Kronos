# G1 mean 与优化 mean：同口径 Qlib 回测对照

> 用户已明确：原始基线是**项目已有 G1 mean**；主目标是优化曲线高于它，不是必须跑赢沪深300，也不要求同时通过此前G10的I/P/S/E。Debian zcode按本计划执行；只复用已有信号，零训练、零新推理、零GPU。

**目标：** 将G1 mean与最新优化G10 A1 mean放入同一套Qlib原生回测，输出同图曲线、逐日差额和窗口末收益差，直接回答“当前优化有没有超过G1 mean”。

**架构：** 直接使用qlib.backtest和TopkDropoutStrategy，Qlib R记录配置/输入/逐日报告/指标/图表，不建立新的实验管理框架；原Kronos与已封存实验不修改。本轮是回测口径对照，不是重新训练或翻改旧实验判据。

**技术栈：** Python3.10+、pandas/numpy、Qlib/MLflow Recorder、matplotlib、pytest、loguru；Path、类型注解、公共Sphinx docstring和中文关键注释。

## 3. 同一套Qlib原生回测设置

使用Debian quant实际导入的Qlib，记录`qlib.__file__`、仓库HEAD与包版本。Mac已发现base默认import路径是`quant-qlib`，故不能凭环境名猜实际代码；两端复现需绑定同一代码版本/配置。

参数依据本仓`finetune/qlib_test.py:QlibBacktest.run_single_backtest`和`finetune/config.py`，固定：

| 项目 | 固定值 |
|---|---|
| 策略 | `TopkDropoutStrategy(topk=50,n_drop=5,hold_thresh=5)`；其他默认值从实际类解析后记录，全臂一致 |
| 执行器 | `SimulatorExecutor(time_per_step='day',generate_portfolio_metrics=True)` |
| 初始资金 | 100,000,000 |
| 市场/基准 | csi300；000300.SH，仅作市场参考线 |
| 成交价 | open |
| 买入费用/卖出费用/最低费用 | 0.001 / 0.0015 / 5 |
| 涨跌停阈值 | 0.095 |
| 交易频率 | day |

**信号时序必须实际验证：** 本机qlib-ddb的TopkDropoutStrategy内部用`get_step_time(...,shift=1)`读取上一交易日信号，不能再照搬旧`qlib_crosscheck_v2.py`额外平移一次。用合成交易日历证明t日信号在t+1开盘执行；若该端实现不同，先核对同源版本而非猜测。截图脚本写了`delay_execution=True`，实际执行器是否支持须查签名/代码；不支持或无效则记录说明，不能把参数写进报告就视为已生效。

这是一套新的统一Qlib比较口径，**不是此前自定义v2结果的延续**：成交价、费用与策略实现有区别。三个模型必须全部重新用该Qlib设置回测，不能把旧v2的G1数字与新Qlib的A1数字并列。

## 4. 指标：直接比较mean曲线，不增加盈利门槛

Qlib逐日报告中的`return`和`cost`按已安装版本核验后使用。主展示与截图脚本相同：

```python
net_daily = report['return'] - report['cost']
curve = net_daily.cumsum()
excess_curve = (net_daily - report['bench']).cumsum()
```

同一窗口的G1与A1报告日期必须一致，沪深300基准逐值一致；基准缺失或报告日期不同，先查原因，不各自删日后比较。

- 主问题的固定答案：`delta_end = curve_A1.iloc[-1] - curve_G1.iloc[-1]`。
- `delta_end>0`：该窗口优化A1高于G1 mean；<0：低于；=0：相同。明确为累计日收益相加口径的百分点差，不称复利收益。
- 相对沪深300的超额曲线只是附图，同一基准相减后A1−G1差不变；不要求必须跑赢沪深300才承认相对改善。
- 两窗各自给结论，不挑较好窗口。两窗均高于G1可描述为“两窗均超过基线”，一高一低写“窗口表现不一致”，均低则“当前优化未超过基线”；不把这一描述升级为统计显著或未来盈利保证。
- 不要求A1曲线每一天都在G1上方；报告高于基线的日期占比和差额曲线作为补充，不能替换固定的窗口末比较。

附表另算复利净值`(1+net_daily).cumprod()`、复利累计收益、最大回撤、日均换手与成本和；与主图cumsum明确分开，不能拼接到同一条收益线上。A0_bestCE附列同样给相对G1差，但不替代A1主结论。
