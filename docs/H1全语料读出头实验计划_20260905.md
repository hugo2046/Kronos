## 1. 设计（2 头 × 2 数据配置，seed 42 先行）

**不变项（逐字复用 R1）**：G1 s100 底座冻结、头结构、IC 损失、AdamW 3e-4 / wd 0.01、
batch 128（= 同一交易日截面随机抽 128 股，IC 在批内计算）、patience 5（早停段日均 RankIC）、
标签 = `close[t+10]/close[t]−1` 按日截面 z-score、评估 canonical 引擎 csi300。

**变量 = 训练数据**：

| 臂 | 头 | 训练标签数据 | 隔离的变量 |
|---|---|---|---|
| H1a-lin / H1a-kda | 线性 / KDA | **2014-01-02~2024-12-17 × csi300 PIT**（时间跨度 ×5.5） | 年数 |
| H1b-lin / H1b-kda | 线性 / KDA | **2014-01-02~2024-12-17 × 全 A PIT 并集**（G1 同语料） | 年数 + 股票广度 |

- 训练步数：每 epoch 2000 步 × epochs ≤ 15，早停段 = **2025-01-01~2025-06-30**（G1 同 val 窗）；
  训练标签末日 2024-12-17（10 日 purge 于早停段前）；
- 评估窗：backtest（2026-01-01~2026-07-24）+ 2025H2（合法：早停段为 2025H1）；
- 两阶段：seed 42 四臂先行；任一臂过 HC1 者补 seed 43/44 确认。

## 2. 判据（跑前冻结）

| # | 判据 | 冻结定义 |
|---|---|---|
| HC1 存活 | 某臂 backtest 双基准 AER > 0 |
| HC2 数据效应 | 同头配对：H1a − R1、H1b − H1a（年数效应 / 广度效应分离）；> 26pp 才许"显著"，带内方向性描述 |
| HC3 对在位者 | 与 G1 s100 配对，同噪声框架 |
| HC4 **终审关闭** | 四臂 backtest 均 ≤ 0 → "读出头在 70× 数据下仍无 oos 存活信息——读出议题终审关闭（架构/目标/数据三维度均已覆盖）"，不做头族/目标/数据窗搜索 |
| 注册 | HC1 ∧ 2025H2 > 0 ∧ 三种子中位双正 → 以规则文档注册进结算对照（复算级新臂） |

**结局地图**：H1a 活而 H1b 更强 → 广度是主因（与 G1 定律一致）；H1a 死 H1b 活 → 广度是必要条件；
H1a 活 H1b 不更强 → 年数是主因；全死 → 饥饿不是死因，读出终审关闭。
