# SAE 残差预测头优化 G1 mean：独立实验计划

> 执行者：Debian zcode，使用 using-superpowers / executing-plans，按 checkbox 执行。用户于2026-09-10同意建立独立SAE优化计划；Mac负责worktree/分支/计划提交推送，Debian实现、实验并回传数据。

**目标：** 保留项目原G1 mean信号，训练一个稀疏自编码残差头，检验同口径Qlib扣费曲线能否超过G1 mean；用相同结构的普通AE残差头判断稀疏约束是否提供额外增益。

**技术栈：** Python3.10+、PyTorch、pandas/numpy、Qlib/R、matplotlib、pytest、loguru；Path、严格类型注解、公共Sphinx docstring与中文关键注释。

## 3. 特征、标签与残差的完整定义

历史输入为t截止的90个交易日OHLCVA；窗口逐列z-score+clip5与G1预测器一致。使用`cross_section_kda.backbone.KronosFrozenBackbone.extract(x,stamp)`，只缓存 `h=hidden[:,-1,:]`（预期832维），不保存全部90步隐状态。tokenizer和predictor恒eval/no_grad/requires_grad=False。

训练/验证需基线预测 `s_G1(t,i)`。先查是否存在具有同底座/参数/输入身份的可复用缓存，否则只为§4固定样本生成一次：L90/H10/N20/T1/top_p0.9/top_k0/clip5/max_context512，mean与G1定义一致。AE/SAE及三个head种子共用这次结果，禁止每个head重推一次G1。

监督目标必须与mean量纲一致：

`y_mean(t,i) = mean(close_i[t+1..t+10]) / close_i[t] - 1`

`e = y_mean - s_G1`，不是单独的close[t+10]/close[t]-1。按交易日历取未来10个**精确日期**；任一所需价格缺失/非有限则该训练样本无标签，不forward-fill、不跳停牌日凑10行。

- 用训练缓存估计每维 `μh, σh`，输入 `x=(h-μh)/max(σh,1e-6)`；只用训练样本，不看验证或测试。
- 用训练残差标准差 `σe=max(std(e),1e-6)`，训练目标 `r=e/σe`。**不减残差均值**，使零输出仍表示零修正，而非自带均值偏移。
- 最终预测 `s_final=s_G1+σe*r_hat`，还原到收益率尺度后再排序。AE/SAE共用μh/σh/σe。
- 若训练残差退化或σe接近数值地板，记录并停止该实验，不放大噪声继续训练。

这里G1训练期预测来自已在该历史上训练过的底座，属于in-sample残差拟合；验证又与G1原验证期有重叠，报告必须披露。不能将它误称样本外教师预测，也不能据此指称使用未来评价期行情。G1固定、头只在规定train训练，测试只做一次比较。

## 5. 头结构、损失与训练预算

两臂结构完全一致，维数从真实h读取：

```text
x[D] → Linear(D,64) → GELU → Linear(64,16) → Sigmoid → z[16]
z → Linear(16,64) → GELU → Linear(64,D) → x_hat[D]
z → Linear(16,1) → r_hat
```

最后残差Linear的weight与bias全0初始化；Encoder/Decoder正常按head seed初始化。无dropout、无额外特征、无基础模型解冻。

损失定义（不搜索权重）：

`L_pred = mean((r_hat-r)^2)`

`L_recon = mean((x_hat-x)^2)`

`p_j = clamp(mean_batch(z_j),1e-6,1-1e-6)`，`rho=0.05`

`L_sparse = mean_j[rho*log(rho/p_j)+(1-rho)*log((1-rho)/(1-p_j))]`

`L = L_pred + 0.1*L_recon + beta*L_sparse`，AE beta0、SAE beta0.001。Sigmoid提供合法(0,1)激活；不把任意未约束隐状态直接代入Bernoulli KL。

训练固定AdamW lr=3e-4、betas=(0.9,0.999)、wd0.01、batch256、clip_grad_norm3、FP32、100epochs，不early-stop，不OneCycle；每epoch完整遍历冻结缓存并按相同seed的顺序shuffle。唯一选点指标为验证`L_pred`最低（并列最早），不用含稀疏项的总loss比较两臂，不读测试收益选epoch。

验证全样本、各日期等权求预测MSE（先每日mean，再跨日mean）；训练样本数每日期64已经等权。预测/重构/稀疏loss、平均激活、低激活占比与梯度范数只作诊断，不作为另挑模型的依据。

稀疏表示不是“必然去噪”；重构好也不意味着收益预测好。零残差保证初始等于G1，仅是实现门禁，不保证训练后仍不劣于G1。
