# MC40同轨迹权重平均实验计划

检验把同一条AdamW轨迹的末段适配器参数等权平均，是否比使用同轨迹最后一个快照产生更好的选股收益。仅一个候选。选定窗口为6000步轨迹最后1000步，取5000、5500、6000步三个当前状态，权重各1/3。协议在生成候选和查看其预测前冻结。两窗此前已多次查看，本轮为开发期比较。

- 来源为上一轮续训的control臂，trainseed100。核验父3000步与已采纳MC40逐张量相同、原checkpoint SHA、续训协议/config/base身份、每个快照文件SHA、12个张量共107712个参数，6000步与该轨迹best逐值相同。
- 对每个同名浮点张量用float64求算术平均，转回原dtype；以独立NumPy实现逐值复核。一个平均后的动态适配器配原G1/tokenizer，无额外梯度更新。该方法借鉴SWA的快照平均，原轨迹是AdamW常数学习率。
- 固定2025H1缓存2048窗口、eval_seed103100，评估三份源快照和平均权重的CE。与既有6000步及原MC40 CE复现核对，记录参数间距离。CE仅诊断，无论高低均对工程核验通过的唯一候选做经济评估。
- 原G1为主基准，已采纳MC40为参照，AdamW6000为隔离平均操作的直接对照。推理沿用42/100各20路径、各流均值等权，W3/W4共520个日期×流。先核对原始日期及股票集合，再核对有限格和池化。W3为126日/37223格，W4为134日/39563格。
- 使用冻结的同口径参照信号和日报，按pctchange/100和±0.095限制，Top50/drop5/hold5、次日open、费用等照旧。真实行情/标签截止2026-07-24，有读前守卫。新预算累计GPU6小时、墙钟8小时，从协议冻结开始，恢复不重置。保留原资源守卫时段。
- 分窗列三项扣费累计差和同日期20日循环块bootstrap区间（5000次，seed100）。收益门槛为两窗均超过原G1及原MC40，风险门槛为两窗夏普不低于MC40且最大回撤幅度不大于MC40。另明确平均相对AdamW6000的方向。按统一规范报告真实收益图、复利、夏普、回撤、费用、换手。独立复核后发布研究索引与证据，实验分支保留，不自动采纳。
