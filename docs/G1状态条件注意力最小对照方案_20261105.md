# G1状态条件注意力最小对照方案

2026-11-05。状态：设计待确认，未实现、未训练、未做新的行情查询或回测。执行目标dev-debian；原G1为模型起点与主基准，MC40仅作竞争参照。风险头按用户要求暂搁，不追加训练。本方案不是此前“在MC40上加倍率”草案的继续执行。

## 选择依据与去重

选择唯一主要候选：**直接在原G1最后两层的自注意力中加入历史状态条件的有界倍率**。原tokenizer、主干原权重、生成头、输入归一化和生成信号公式保留。原G1模型中不加载MC40适配器，不加载风险头，不修改持仓规则。

为何优先：风险头是在固定表示后学习，Q1选择初始化，未留下表示读取增量；这不足以证明G1表示没有信息，但降低了继续更换相近读出头的优先级。此候选改变形成表示时的历史加权，保留原生生成式出口。研究索引未发现它已被直接执行：此前注意力草案未运行；MC40是块输出后状态残差、TAS1是双遍重读、LoRA是投影权重更新，与本候选不同。不能把不同结构等同于已有成功依据。

备选比较：
- Dish-TS/SAN式改归一化：涉及冻结tokenizer输入分布，需先证明量化兼容性，本轮不同时做。
- TimeMixer式多尺度分支：会同时改变尺度表示、容量和输出混合，难以解释哪一项产生增量，本轮不选。
- 非平稳注意力倍率：保留已有数据与生成语义，两个训练臂即可检验“全局校准”与“状态条件化”。选择理由是机制可归因与原模型兼容，不是论文证明它能提高A股收益。

## 论文事实与本项目假设

[Non-stationary Transformers原论文](https://arxiv.org/abs/2205.14415)讨论平稳化可能削弱非平稳信息，提出平稳化与去平稳注意力；[作者代码](https://github.com/thuml/Nonstationary_Transformers/blob/main/ns_layers/SelfAttention_Family.py)对softmax前分数施加输入相关tau与delta，并保留因果mask。

本轮只借鉴tau，不取delta、不改输入标准化。这不是原论文完整复现；其连续时序推导和误差结果不能直接外推到Kronos的离散量化或金融收益。对比备选的[TimeMixer原论文](https://arxiv.org/abs/2405.14616)采用多尺度分解、混合和预测器组合，不能仅抽一个模块便继承论文效果。

待检验假设：原G1在不同历史波动状态下，适宜的注意力集中程度可能不同。显式提供未标准化历史的波动信息，或能改善随后生成分布与选股排序，最终改善扣费收益风险。**尚未证明原G1回撤主要由注意力问题引起，也未证明“高波动就应看更短历史”。**

这里的tau是模型内部注意力倍率，不是生成采样温度T；采样T=1、top_p=.9、top_k=0保持原协议。倍率不会重排同一query原来的QK分数，只改变softmax集中程度；不称其为重新发现时间关系、直接选择短/长窗口或恢复全部被量化损失的信息。注意力熵和近期注意力占比仅为诊断，不是因果解释。

## 一个结构、两个训练臂

原注意力：A=softmax(QKᵀ/√d + mask)V。

候选：A=softmax(tau_l(z)QKᵀ/√d + mask)V；tau_l(z)=exp(0.25*tanh(b_l+w_lᵀz))。

- 仅最后两层，每层共享所有head的一个倍率，动态臂共8个新增参数，b和w均为0初始化，tau初始为1、范围约[0.779,1.284]。范围为本项目保守固定选择，不是论文最优值。
- 静态臂只学两个b，w固定0；动态臂学两个b和六个w。有效自由度分别为2/8，不宣称完全等容量。两臂相同数据、批次、更新数、初始化与随机流。
- z沿用已核实的history_state：log(std20/.02)、log(std20/std60)、log(std5/std20)，简单收益、总体标准差ddof0、epsilon保护后裁剪[-5,5]。只用截至原点t、含t当天收盘的90个市场交易日（t−89至t）原始收盘价。它与风险头的ddof1/sqrt10尺度是不同定义，不混用。
- 每个原点的z和原G1历史归一化统计仅取同一t−89至t窗口，在未来10步生成中固定；扩展20路径时显式repeat_interleave，不能读取真实未来状态。训练仅监督历史90日之后的未来10token位置：首个未来标签t+1由原点位置t预测，输入/目标移位对齐，按原损失的89..98位置实现，不从标签区间估计状态或归一化统计。
- 在RoPE之后、原SDPA之前对Q乘tau，保留原mask/scale/后端调用。tau1必须与原G1逐值保真；若实现迫使更换注意力后端，先解决计算路径对照，不能将数值变化冒充机制作用。
- 冻结原G1参数，训练时保留tau至损失的梯度；不把整个前向置于no_grad。冻结模型采用eval模式，消除dropout差异；原双头未来token CE、use_teacher_forcing=False保留，粗头内部抽样的训练/验证RNG分别固定。
