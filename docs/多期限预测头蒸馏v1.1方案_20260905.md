# 多期限预测头蒸馏 v1.1 方案（收益尺度接口 + 最小拟合试验）· 2026-09-05

> 独立于 v1 封盘（`docs/多期限预测头蒸馏结果_20260905.md`）的后续预注册。
> 立项依据：v1 诊断修复 #1 证实教师生成带 20% dropout 噪声——v1 门禁
> FAIL 的归因存在混杂（见 `docs/多期限预测头蒸馏诊断修复_20260905.md`）。
> v1.1 回答两个被污染前无法回答的问题：**管线容量**（学生能否逐股拟合
> 干净教师）与**尺度口径**（蒸馏目标的归一尺度是否压制了信号学习）。
> 判据跑前冻结；一次开封；失败不搜索；不改 v1 封盘产物。

## 0. 前提与范围

- 代码基线：a70bab6 + 诊断修复提交（教师 eval 强制、缓存身份链、门禁
  seed/前置）。教师一律 eval 态生成，`model_eval=True` 入身份——与 v1
  dropout 态分片天然隔离，新产物写新 run 目录。
- 范围仅两件事：(A) 收益尺度接口调整；(B) 最小拟合试验。
  **不**重跑 v1 pilot 门禁、**不**解锁 main/D2、**不**做任何回放收益判读。
- 预算上限：4 GPU 时（实际预计 <1 GPU 时）。seed 固定 42，单种子。

## A. 收益尺度接口（单变量，冻结）

- v1 现状：`scale[h] = max(std_train(y_real[:,h]), 0.01)`（§4.3），用于
  S/D/E 全部归一。诊断假设：蒸馏目标（教师收益）与真实标签的截面分布
  尺度不同，共用同一 scale 可能使 D 项相对欠权——但**本方案不改默认值**，
  只把尺度口径做成可配置并冻结为单变量对照。
- 接口：`DHeadConfig.scale_source: str = "train_real_std"`，取值白名单
  `{"train_real_std", "teacher_r0_std"}`；入 protocol hash（改值=新协议，
  全链产物隔离）。`train_r0_std` = 蒸馏目标 replica0 的逐期限
  `max(std, 0.01)`。其余一切不变。
- v1.1 实验只用 `train_real_std`（与 v1 同口径，作容量检验的干净重跑）；
  `teacher_r0_std` 仅注册接口，不在本轮使用（避免双变量）。

## B. 最小拟合试验（sanity fit，判据冻结）

**命题**：修复后的管线（干净教师 + 冻结底座 + 多期限头）在**过拟合
状态**下能否逐股逼近教师信号——区分"容量/管线不足"与"数据不足以
泛化"。

- **数据**：pilot 清单的前 **8 个训练日**（≤512 样本，全部来自已冻结
  pilot train 清单，不新取数）；教师用 eval 态 G1 重新生成 3-replica
  （N=20，T=1.0/top_p=0.9/top_k=0，keyed RNG 不变）。
- **训练**：D0 配置（纯蒸馏损失）但 `disable_early_stop=True`、
  `max_epochs=200`、lr 不变 3e-4、patience 失效；训练与"验证"都用同 8 日
  （过拟合检验，无泛化声明）。产物 run 名前缀 `v11-`。
- **判据（跑前冻结）**：

| # | 判据 | 定义 | 通过动作 |
|---|---|---|---|
| V1-1 容量 | 末 epoch 训练 D（normalized_mse vs 干净 r0）≤ R_clean | R_clean = 干净教师 val replica1/2 的按日等权 MSE_norm（eval 态重生成后实测） | 证明头+冻结底座容量足以逐股拟合教师信号；v1 FAIL 归因收窄为"数据/泛化不足或教师信噪比不足" |
| V1-2 尺度 | （描述性）末 epoch 各期限 |D|/scale 与截面信号/R_clean 的对比表 | 仅入结果文档，不设通过线 |
| V1-3 拒绝 | V1-1 未过 | — | 结论"管线容量不足"，头结构或冻结策略需另立方案；不做结构搜索 |

- **教师噪声重测**：干净（eval 态）教师 val 3-replica 重生成后，报告
  R_clean 与 v1 的 R=0.0220 的差（dropout 噪声占比的量化估计）。
- **产物**：全部写 `DHEAD_ARTIFACT_ROOT`（新 run 目录，身份隔离）；
  结果文档追加至 `docs/多期限预测头蒸馏结果_20260905.md` 的 v1.1 附录
  或独立 `docs/多期限预测头蒸馏v1.1结果_<日期>.md`。

## C. 执行序列与预算

1. 教师重生成：8 训练日（512 样本×3）+ val 全量（1,024×3）≈
   4,608 次 × ~112ms ≈ **9 分钟**；
2. 训练：8 日 × 200 epoch × ~0.3s ≈ **~10 分钟**；
3. 评价与文档：CPU。合计 <1 GPU 时（上限 4）。
