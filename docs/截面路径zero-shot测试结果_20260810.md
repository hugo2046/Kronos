## 1. 实验口径（全部预注册，见计划 §0）

| 项 | 取值 |
|---|---|
| zero-shot | 官方 `NeoQuasar/Kronos-Tokenizer-base` + `NeoQuasar/Kronos-base` 直接推理，不微调，Tokenizer 冻结 |
| 频率 / 回看 / 预测 | 日频，L=90，H=10 |
| 信号 | `signal_t = mean(pred_close[t+1..t+H]) / close_t - 1`，截面排序 |
| 归一化 | `KronosPredictor.predict_batch` 内置（窗口 z-score + clip 5），不自写 |
| 采样 | `T=1.0, top_p=0.9, top_k=0, sample_count=5`，全程 `torch.manual_seed(42)` |
| 股票池 | 沪深300，point-in-time 成分（逐调仓日重取，无幸存者偏差） |
| 回测区间 | `2022-01-04 ~ 2026-07-22`，每 10 个交易日一个调仓日，**111 期** |
| 调仓频率 | 每 10 个交易日（与 H=10 对齐，不重叠） |
| 分组 / 成本 | 分 5 组等权；多空扣单边 15bp（双边换手上限 200% 每 10 日） |
| 数据末日 | 2026-08-07 |

全部口径锁在 [`cross_section/config.yaml`](../cross_section/config.yaml)，阶段间不许漂移。

### 关 2：相对基线（§6.2，未进入，仅记录对照）

即便不否决，Kronos 的 |RankIC|=0.0098 并未明显超过最强基线动量（|RankIC|=0.0094），多空净值（-10.57% 净年化）也远逊于动量（+0.66%）——**不会**同时超过两条基线中较强者。两条基线本身在 csi300 日频 111 期上也基本无效（动量 ICIR=0.045、反转 ICIR=-0.045），说明本区间 A 股大盘股短周期价量因子普遍弱，但 Kronos 在这个"低基数"环境里依然没有任何增量。

## 4. 结论与判读

1. **官方 Kronos-base 零样本的"H 日平均预期收益率"在 A 股 csi300 截面上不构成有效因子**。RankIC 均值 +0.0098、ICIR +0.053，均显著低于预注册门槛；分组收益无单调性；多空组合净年化 -10.57%、最大回撤 -57.69%。
2. Kronos 的预测路径本身是"正确"的（阶段 2 反归一化、确定性、非退化全过，预测值与输入同数量级），问题不是工程 bug，而是**零样本生成式预测折算的预期收益率在截面上没有选股 alpha**。这与"方向分类头"上轮实验的证伪（macro-F1 ~0.38）方向一致：未微调的 Kronos-base 对 A 股个股方向/截面的判别力不足。
3. **关 1 否决即停**。按预注册纪律，不做 H / lookback / 采样参数 / 池的搜索；这类搜索在 111 期样本上属于过拟合，不是科学结论。

## 5. 局限性（计划 §7.3，写全）

- **幸存者偏差已消除**：成分股逐调仓日按 `list_pool_at` 重取 point-in-time 成分，不做固定池。本节不照抄旧版"当前成分"口径。
- **停牌股票在该调仓日被整只剔除**，构成轻微选择性（实测 halt 1–7 / 300 每期，平均 ~4–5 只），不前向填充（填充出的假 K 线会被 Kronos 当真实形态编码）。
- **可交易性未建模**：涨跌停、复牌首日的可交易性在首轮不建模，记录为局限。
- **ST 未剔除**（`filter_pipe` 默认关闭）。本 DolphinDB 实例有 `st` 表（2025-06-16 实测 182 只 ST），如需可开启，但开启即改变股票池，属另一组实验，不要在同一轮里混。
- **结果绑定 DDB 实例 `100.114.247.25:8848` 与数据末日 2026-08-07**；后复权口径、`tradestatuscode` 语义均绑定该实例。
- **`notebooklm` 核对未执行**（见 §4.1），与东证报告数字的逐项对照缺失。
- **111 期 / 单池 / 单区间**：结论严格针对 csi300 / 2022-01-04~2026-07-22 / 日频 H=10；不外推到其它池、其它频段或更短样本。

## 7. 下一步建议

- **不建议**在 zero-shot 路线上继续做参数搜索（已预注册否决，111 期过拟合风险高）。
- 若仍要评估 Kronos 在 A 股截面的价值，**唯一合理的下一步是 A 股微调增强**（另立计划）：在 Kronos-base 上用 A 股日频做有监督微调，再回测同一截面口径。这超出本 zero-shot 计划范围。
- 复用价值：本实验落地的 `cross_section/` 管线（构窗 → predict_batch → 信号 → 标准因子检验 → 基线对照 → 预注册判读）可直接复用于微调后的模型评估，口径已全部锁定、可复现。
