## 1. 实验口径（全部预注册，见计划 §0）

| 项 | 取值 |
|---|---|
| zero-shot | 官方 `NeoQuasar/Kronos-Tokenizer-base` + `NeoQuasar/Kronos-base` 直接推理，不微调，Tokenizer 冻结 |
| 频率 / 回看 / 预测 | 日频，L=90，H=10 |
| 信号 | `signal_t = mean(pred_close[t+1..t+H]) / close_t - 1`，截面排序 |
| 归一化 | `KronosPredictor.predict_batch` 内置（窗口 z-score + clip 5），不自写 |
| 采样 | `T=1.0, top_p=0.9, top_k=0, sample_count=5`，全程 `torch.manual_seed(42)` |
| 股票池 | 沪深300，point-in-time 成分（逐调仓日重取，无幸存者偏差） |
| 回测区间 | `2022-01-04 ~ 2026-07-22`，每 10 个交易日一个调仓日，**111 期** |
| 调仓频率 | 每 10 个交易日（与 H=10 对齐，不重叠） |
| 分组 / 成本 | 分 5 组等权；多空扣单边 15bp（双边换手上限 200% 每 10 日） |

## 4. 结论与判读

1. **官方 Kronos-base 零样本的"H 日平均预期收益率"在 A 股 csi300 截面上不构成有效因子**。RankIC 均值 +0.0098、ICIR +0.053，均显著低于预注册门槛；分组收益无单调性；多空组合净年化 -10.57%、最大回撤 -57.69%。
2. Kronos 的预测路径本身是"正确"的（阶段 2 反归一化、确定性、非退化全过，预测值与输入同数量级；前向收益对齐经独立复算为零偏差），问题不是工程 bug。
3. **关 1 否决即停**。按预注册纪律，不做 H / lookback / 采样参数 / 池的搜索；这类搜索在 111 期样本上属于过拟合，不是科学结论。
4. **⚠️ 结论的适用边界（2026-08-10 核对后新增，务必连同读）**：本结论**仅对本实验口径成立**
   ——Kronos-**base** / 采样 5 次 / 每 10 日调仓 / 5 分组多空 / 2022-01~2026-07。
   论文与东证报告在 **zero-shot 同设定**下得到正面结果（AER 20.8% / IR 1.65），
   但其口径在模型规模、采样次数、回测区间、调仓频率、组合构建五处均与本实验不同（见 §4.1.2），
   且在论文那一年窗口内本实验信号的 RankIC 亦达 +0.0389（见 §4.1.3）。
   **因此不得据本文档断言"Kronos 对 A 股截面无价值"**，只能说"本口径下未通过预注册门槛"。

### 4.1 与论文 / 东证报告的核对（§6.4，2026-08-10 已执行）

经 `notebooklm` 查询笔记本 `kronos论文与a股落地分析`（Mac 端执行，问答原文见
[手动问notbook回复.md](./手动问notbook回复.md)），核对结论如下。

#### 4.1.1 关键事实

1. **东证报告的 A 股实证是引用论文的投资模拟实验，且确为 zero-shot**（未在 A 股微调），
   与我们的设定一致——**不能用"报告用了微调"来解释分歧**；
2. **论文/报告未报告 A 股截面的 IC / ICIR**。A 股部分只报告组合业绩：
   `Kronos_large` 年化超额收益 **AER = 20.8%**、信息比率 **IR = 1.65**（long-only，非多空）；
3. 论文中的 **IC 0.0702 / RankIC 0.0675 属于"收益预测任务"的整体测试集指标**
   （跨股票 / 加密 / 外汇），**不是 A 股截面选股 IC**。
   **拿我们的 0.0098 去对比 0.0675 是错误对照**，本文档不做此对比；
4. 信号折算公式与窗口**与我们完全一致**：`R = (mean(pred_close[t+1..t+H]) - p_t) / p_t`，
   L=90 / H=10，成本单边 0.15%。

#### 4.1.2 口径差异对照（这是分歧的主因）

| 维度 | 论文 / 东证报告 | 本实验 | 是否一致 |
|---|---|---|---|
| 信号公式 | `mean(pred_close)/p_t − 1` | 同左 | ✅ |
| 回看 / 预测窗口 | 90 / 10 | 同左 | ✅ |
| 交易成本 | 单边 0.15% | 单边 15bp | ✅ |
| **模型规模** | **Kronos_large**（最佳结果） | **Kronos-base** | ❌ 论文证实存在 scaling law，规模越大单调越好 |
| **采样次数 N** | **20**（IC/RankIC 随 N 单调改善） | **5** | ❌ |
| **回测区间** | **2024-07 ~ 2025-06**（1 年，刻意置于预训练截止 2024-06 之后以隔离） | **2022-01 ~ 2026-07**（4.5 年，其中 2.5 年落在预训练覆盖期内） | ❌ |
| **调仓频率** | **每个交易日**（top-k/drop-n，最少持有 5 天） | **每 10 个交易日** | ❌ |
| **组合构建** | **long-only top-50 等权**，对指数算超额 | **5 分组多空 Q5−Q1** | ❌ |
| **报告指标** | AER / IR | RankIC / ICIR / 多空年化 | ❌ 不可直接换算 |
| 股票池 | 沪深300 + 中证800 | 沪深300 | 部分一致 |

**九个维度中六个不同**，其中"模型规模、采样次数、回测区间、调仓频率、组合构建"五项都指向
论文口径更有利。因此**本实验的负结果与论文的正面结果不构成直接冲突**——我们没有复现论文口径。

#### 4.1.3 子区间对照（事后分析，非预注册）

论文窗口刻意置于预训练截止之后。按同一切分复算本实验信号：

| 子区间 | 期数 | Kronos RankIC | ICIR | t | 10 日动量 RankIC |
|---|---|---|---|---|---|
| 全区间 2022-01~2026-07（**预注册**） | 111 | +0.0098 | +0.053 | +0.56 | +0.0094 |
| 预训练覆盖期内 <2024-07 | 61 | +0.0027 | +0.014 | +0.11 | +0.0074 |
| 预训练之后 ≥2024-07 | 50 | +0.0185 | +0.105 | +0.74 | +0.0119 |
| **论文窗口 2024-07~2025-06** | **24** | **+0.0389** | +0.209 | +1.02 | −0.0222 |

**必须如实指出**：在论文所用的那一年窗口内，本实验的 Kronos 信号 RankIC 达到 **+0.0389，
高于预注册的 0.02 门槛**（同期动量为负 −0.0222），方向上与论文的正面结论一致。

但同样必须指出该结果**不足以推翻预注册结论**：

- n=24，**t=1.02，统计上不显著**；ICIR 0.209 仍低于 0.3 门槛；
- 这是**看过全样本结果之后**做的子区间切分，存在多重比较问题——尽管窗口本身由论文外生指定
  （非我们为好看而挑），仍属事后分析；
- 子区间差异更可能是**市场环境（regime）**驱动而非"预训练泄露"：2022-01~2024-06 是 A 股
  持续调整与风格切换期，同期动量类因子同样孱弱。

**结论**：分歧的主因是口径不可比 + 区间选择，而非我们的管线有错（前向收益对齐已独立复算至
零偏差，见 §2）。正确的下一步是**先按论文口径复现**，而不是据本文档否定 Kronos 的截面价值。

## 5. 局限性（计划 §7.3，写全）

- **幸存者偏差已消除**：成分股逐调仓日按 `list_pool_at` 重取 point-in-time 成分，不做固定池。本节不照抄旧版"当前成分"口径。
- **停牌股票在该调仓日被整只剔除**，构成轻微选择性（实测 halt 1–7 / 300 每期，平均 ~4–5 只），不前向填充（填充出的假 K 线会被 Kronos 当真实形态编码）。
- **可交易性未建模**：涨跌停、复牌首日的可交易性在首轮不建模，记录为局限。
- **ST 未剔除**（`filter_pipe` 默认关闭）。本 DolphinDB 实例有 `st` 表（2025-06-16 实测 182 只 ST），如需可开启，但开启即改变股票池，属另一组实验，不要在同一轮里混。
- **结果绑定 DDB 实例 `100.**.**.25:8848` 与数据末日 2026-08-07**；后复权口径、`tradestatuscode` 语义均绑定该实例。
- **未复现论文口径**（核心局限，见 §4.1.2）：模型规模用 base 而非 large、采样 5 次而非 20 次、
  每 10 日调仓而非每日、5 分组多空而非 long-only top-50、区间跨越预训练覆盖期。
  这五项差异均指向论文口径更有利，故本实验**不构成对论文结论的证伪**。
- **回测区间有 2.5 年（61/111 期）落在 Kronos 预训练数据覆盖期内**（预训练截止 2024-06）。
  该重叠不构成传统意义的标签泄露（预训练目标是 K 线生成而非未来收益），但使本实验区间与论文的
  严格时间隔离设定不可比。
- **111 期 / 单池 / 单区间**：结论严格针对 csi300 / 2022-01-04~2026-07-22 / 日频 H=10；不外推到其它池、其它频段或更短样本。
- §4.1.3 的子区间对照为**事后分析**，n=24 时 t=1.02 不显著，不可作为独立结论引用。

## 7. 下一步建议（2026-08-10 核对后重写）

原版本建议"唯一合理的下一步是 A 股微调"。**该建议已作废**——核对显示论文/报告在 zero-shot
同设定下取得正面结果，且东证报告明确将微调列为"主动优化方向"而非"效果不足的补救"
（报告原文："后续可以重点探索两类路径…二是在预训练表示基础上进行轻量化微调"）。
在未复现论文口径之前就转向微调，会把"口径没对齐"误当成"模型不行"。

**新的优先级：先复现，再判断。**

1. **P0 — 按论文口径复现**（另立计划）。逐项对齐 §4.1.2 中不同的五处，优先级从高到低：
   - 回测区间改 **2024-07 ~ 2025-06**（论文的时间隔离窗口）；
   - 组合构建改 **long-only top-50 等权 + 每日调仓 + drop-5 + 最少持有 5 天**，
     指标改 **AER / IR**（与论文可直接比对）；
   - 采样次数 **5 → 20**（论文证实 IC/RankIC 随 N 单调改善）；
   - ~~模型 base → large~~ **不可行（2026-08-10 勘误）**：README Model Zoo 明确
     `Kronos-large`（499.2M）**未开源**，可用上限即 base（102.3M）。复现目标应对齐论文中
     base 规格的结果（附录 Table 10，需从 arXiv 原文获取），而非 large 的 AER 20.8%；
