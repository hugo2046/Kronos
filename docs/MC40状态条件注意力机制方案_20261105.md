# MC40状态条件注意力机制方案

2026-11-05。状态：研究设计待确认，未实施、未训练、未查询行情。用户已指定dev-debian、原G1主基准、MC40参照及封存不动。本轮先把方案想清楚；以下新增参数和预算为建议值，不是已获得实验结果。

## 选择与依据

两标量测试期适配暂搁。它的W3/W4净累计30.3974%/2.5568%均低于MC40，同成熟样本RankIC仅W3略升。不能由此证明状态信息无效，也不能证明注意力是失败根因。

选择：在冻结MC40最后两个Transformer块的自注意力中，增加由原有三维历史状态决定的有界logit倍率。研究问题仅为：**MC40已具备状态条件残差后，状态条件的注意力集中程度是否还有预测增量？**

比较过的替代路线：Dish-TS/SAN类归一化改造会改变冻结tokenizer所见分布，先不选；TimeMixer启发的多尺度分支会增加结构和容量混杂，先不选。注意力倍率已在10月30日论文笔记提出，但本次核对索引未见直接执行记录。MC40原适配器在块输出后加状态残差，本方案插在块内部softmax之前；不是重复训练MC40，也不是重开两标量TTA。

论文依据是Non-stationary Transformers（NeurIPS 2022）。原文同时提出平稳化和去平稳注意力；作者实现用tau与delta修改softmax前分数。本方案只取tau思想，不取delta、不改标准化，属于Kronos离散生成模型的受控迁移，不是原论文复现，也不能继承其MSE提升结论。

- 原论文：https://arxiv.org/abs/2205.14415
- 作者实现：https://github.com/thuml/Nonstationary_Transformers/blob/main/ns_layers/SelfAttention_Family.py
- 已有笔记：[时序适配论文核查](Kronos时序适配论文核查_20261030.md)

## 机制、结构和不能声称的内容

原注意力为softmax(QKᵀ/√d + causal_mask)V。候选改为softmax(tau_l(z) QKᵀ/√d + causal_mask)V。

每个末层共享所有head的一个倍率：tau_l(z)=exp(0.25*tanh(b_l+w_lᵀz))。z沿用MC40原有三维状态及原有预处理，不引入新特征或重新按测试分布标准化。两层共8个新增可训练参数，全部零初始化，tau初始为1、范围约[0.779,1.284]。原G1、tokenizer、全部MC40适配参数冻结。该范围是本项目保守设计，不来自论文最优值。

tau>1让每个query更集中于已有高分key，tau<1使其更分散；它不会在同一query中重新排列原QK logits，也不直接选择短/长历史，不能将其称为学到了新的相关性排序。是否更关注近期，只能用事后诊断检验，不能预设。与给最终股票分数做共同单调变换不同，各股票隐状态及生成分布会改变，但排序增益仍待验证。

已只读核查dev-debian的model/module.py：MultiHeadAttentionWithRoPE在RoPE后调用因果SDPA。建议在RoPE后对Q乘逐样本tau，保留原缩放、V、mask及SDPA后端；避免换成另一套attention实现导致数值混杂。原state_adapter/model.py将残差放在块输出后，两插入位置确实不同。

状态只依赖预测原点90日已知历史，对该样本整个未来生成保持固定；推理扩成40条路径时显式复制状态，不允许静默广播。训练只计原未来10token位置损失，不给历史位置增加使用原点状态的辅助损失。冻结层仍保留到tau的梯度链。

## 最小可证伪对照

|对象|改动|作用|
|---|---|---|
|原G1|原冻结模型及原信号|主基准|
|MC40|已采纳权重，tau=1|参照与恒等接线控制|
|静态tau|每层只学b，w固定0|区分总体注意力校准与状态条件化|
|动态tau|每层学b及三维w|唯一主要候选|

静态2个有效参数、动态8个，不宣称等有效容量。两训练臂同批次、同更新数、同初始化和RNG，均从冻结已采纳MC40上学习新增参数，不续训原适配器。静态不是另一个可择优上位的候选，完整报告保留其负结果。

补充机制诊断只在2025H1开发验证期：将动态tau中的z替换为训练期固定均值，以及按预先固定seed100在同日截面打乱z。原MC40适配器始终接收真实z，避免同时破坏两个机制。该诊断不训练第三个候选，也不作为新的部署方案；置乱造成输入不匹配，不能单独当因果证明。

## 分阶段执行与停止

A：工程与数据先导。建立独立dev-debian工作树（建议名Kronos-mc40-attn-tau，分支codex/mc40-attn-tau-20261105，尚未创建）。绑定源代码、原G1、tokenizer、MC40权重和数据缓存SHA。tau=1在原固定开发日上逐值复现MC40 logits、两流信号；用合成数据验证未来token扰动不影响早位置、padding、RNG、断点和冻结权重不变。安全测试显式白名单并禁网，绝不全仓pytest。接线无法保真则停止研究解释，先修工程。

B：离线最小配对。建议沿用原训练语料、窗口抽样和2025H1验证cache；seed100、batch64、AdamW lr3e-4、betas(.9,.95)、wd.01、clip1、3000更新，每500步快照。两臂新增参数相同优化设置；这不是对107712原参数继续训练。先审计固定语料标签终点和验证隔离，再冻结具体配置。按原验证CE规则选点，含初始化步0，步数并列时选较早者；不按W3/W4收益挑选。2025H1亦已反复使用，仅属开发证据。

记录梯度是否非零、tau与边界距离、各层注意力熵、原点最后query在最近5/20/60日的注意力质量、粗/细token CE，以及同股票同10日标签的日均RankIC。注意力统计仅为机制探针，不把注意力权重当作特征因果解释。

B阶段停止：非有限数、冻权重变化、无有效梯度、tau=1保真失败均为工程失败；步0被选中或动态验证RankIC不高于MC40且不高于静态时不进入长经济确认。若仅CE下降，不判预测成功；若动态不胜静态，不能宣称状态条件化有效。若接近边界，不扩大范围追胜。门槛是开发筛选，不是独立显著性结论；所有候选数必须披露。

C：仅当B阶段通过才进行冻结后完整W3/W4评估。动态与静态均用seed42/100各20路径，两个流信号等权，原G1有限格W3 126/37223、W4 134/39563。一次性评估固定两候选，不能看到结果后缩窗、挑层、改范围、加head。预测主指标：各窗动态相对MC40及静态的配对10日RankIC增量，原G1同时列出；同日同资格目标缺失规则，不截掉收益曲线尾日来迁就标签。末10日起点缺完整标签时明确预测指标覆盖，经济回测仍用全窗口。

探索性预测晋级要求：两窗相对MC40与静态的日均RankIC增量都为正。对四个差额使用20交易日循环块、5000次、seed100，给95%区间及Holm校正检验；若区间跨零只能称方向一致，不能称已证实。推理两seed不是两份独立市场样本。经济门槛另列，两窗收益、夏普、回撤与原G1/MC40同口径比较；不以回测收益取代预测判据、不自动采纳。
