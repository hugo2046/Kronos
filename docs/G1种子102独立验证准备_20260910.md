# G1 seed102 对 seed100：独立验证准备与边界

> 承接用户“不能靠过拟合或偷看答案找到胜出方案”的要求。本提交完成图片归档修复并提供前向验证设计；**当前只做准备，不读取已有forward，不启动新训练、模型推理或定时采集，不修改原结算协议。**

## 1. 为什么不再重跑W3/W4找赢家

`ee77884`的当前Qlib结果已核验：max在W3相对G1 +3.21pp、W4 −2.95pp；C1在W3 −3.00pp、W4 +1.59pp，均非两窗胜出。

附表s102相对s100在W3约+1.94pp、W4约+1.69pp，但这是查看全部结果后发现的。现在选择s102已带有历史筛选偏差，因此只列为待验证候选，不把这两窗再称独立测试。

本轮不构建“W3选max、W4选C1”，不挑新的权重/seed/日期/费用规则，不从同一历史重复筛选。不改变G1 s100当前基线地位。

## 2. 固定唯一候选与比较口径

- 基线：已有G1 s100 predictor + 原G1 tokenizer，mean信号。
- 候选：已有G2/G1 s102 predictor + 同一tokenizer，mean信号。
- 两者仅训练种子产物不同，本协议不重新训练，不称一种新架构。推理L90/H10/N20/T1/top_p0.9/top_k0、same batch32/代码顺序/随机规则，正式启动前绑定两个权重和tokenizer完整SHA、代码版本与参数。
- 只比较这两臂，不追加s101/103/104/max/min/集成作为可选择赢家。旧协议可能包含其他臂，它们仍按旧协议处理，与本检验分开。
- Qlib固定当前用户口径：TopkDropout50/5/hold5、open成交、买0.001/卖0.0015/min5、limit_threshold0.095、资金1亿；同一天PIT csi300资格、同行情快照、同可交易性。
- 主量：`D(t)=cumsum(net_return_s102-net_return_s100)`；主问题是观察窗末D是否>0，不增加必须跑赢沪深300的门槛。复利、MDD和成本另列，不混入cumsum主曲线。
- 每个账户独立，从观察窗开始持有现金；不继承各自旧窗口的期末仓位。Qlib内部t→t+1时序先合成验收，不叠加手动shift。

## 3. 真正独立的观察窗：正式准备完成后才产生

不能现在拿已有2026-07-25后的数据套这条规则；它们继续封存。本协议不授权提前开封。

正式观察开始必须同时具备：策略与模型/推理身份冻结、登记代码与合成测试通过、采集责任与输出位置确定、开始日期规则已经提交盖章。**本计划提交本身不冒充这些条件已经完成。**

- T_freeze：上述准备完成时最后一份冻结记录的时间。
- D0：T_freeze所在日期之后的第一个交易日；D0收盘产生第一份可登记信号，供D1开盘决策执行。
- D1..D120：之后固定120个交易日的收益观察窗；需D0..D119的120份事前决策信号。D120收盘后才允许一次开封。
- 窗口定义完全由交易日历和T_freeze决定，不能根据期间涨跌更换开始日、跳过亏损日、滚动到更好区间或临时延长到通过。
- 120日首读同时展示前60日与后60日的差额；不在第60日提前查看绩效，不做中途可选停止。
- 120日是本方案采用的固定观察设计，不保证统计功效充分，更不保证候选成功。不能用“数据太少”无限延长同一次检验。

若错过按规则确定的D0或登记发生缺口，标记协议执行失败/证据不足；不能事后重算并把重算信号称事前登记。不要无说明平移观察窗。新的起点若需另立，须在新结果出现前另行记录偏差与原因。

## 4. 登记与不看答案的分工（未来执行要求，本轮不启用）

- 两臂信号按(date,instrument)同时保存，附权重/代码/输入/输出SHA、生成时间、下一可执行交易日和推理随机规则。信号生成只使用t截止行情，未来时间戳只能是日历日期。
- 信号必须在对应D+1开盘前完成不可覆盖的登记；过时写入记late，不悄悄覆盖。不能先看当日收益再补“昨天预测”。
- 沿用已有采集设施需先检查是否确有同语义身份与时序保证；不能只凭文件名称相似就复用。原登记cron与原forward文件不修改。
- 运行健康检查只报告是否准时、是否完整、身份是否一致；不输出期间收益、曲线、排名或哪个seed更好。
- 数据采集与绩效读取权限/入口分开；评价入口必须有日期门禁。门禁未满足时拒绝加载收益，而不是算完后不展示。
- 两臂缺股票信号/迟补/校验失败必须同时记录，不依据候选表现选择剔除。若无法在固定共同资格与原规则下有效执行，主比较标不可判。

## 5. 一次开封时如何报告（本轮不实现真实开封）

1. 先验证信号事前登记证据、哈希与缺口；不通过则报告有效性不足，不宣称赢家。
2. 两臂同Qlib配置、同日历/数据快照回测，主结论为D120>0或≤0；负结果不改规则重试。
3. 同时给前60日D、后60日D：全期与两段均正可描述为“本次独立观察窗及两段均超过基线”；仅全期正则报告分段不一致。它们不是三个独立样本。
4. 配对日净收益差的区间估计为附表：固定moving-block bootstrap，block=10交易日，重复2000次，随机seed17，报告全窗累计差的95%区间；不足/退化如实标不可估，不选择更容易显著的block或方法。区间跨0则明确证据仍不确定，不把D>0写成已证明显著。
5. 保留“s102由历史筛选而来”的背景，但独立观察数据不曾用于选择。一次正结果也不能数学保证不存在过拟合或未来失效，更不能自动替换在位者/实盘。

本设计与2026-08-18原结算计划并行记录，**不增加、删改或替代旧计划判据**。如原计划的停止条件先触发，本项目任何新运行都遵从用户当时的决定，不用本设计绕开旧承诺。
