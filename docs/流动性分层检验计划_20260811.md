## 1. 规范（用户 2026-08-11 指定，本轮起生效）

- **分组/因子分析一律用 `analyzer.analyze_factor`**：`skip_paused=True`、`skip_one_word_limit=True`
  （帖子的"简单回测"没有这两项，这正是补硬伤③）、`delay=1` 保持默认（T+1）、

  但其"随机占位零点门禁"思想保留：P 组随机信号必须过同配置 `qlib_bt`，
  档内 spread 与超额都应 ≈ 0；

## 2. 实验设计（v2，2026-08-11 按用户指正重构）

> **v2 修订**：v1 的"逐日逐档生成信号"把分档与推理耦合——换分档参数需重推理、
> 档间重叠股票重复计算、月末调仓循环非向量化。v2 改为
> **"掩码先行 → 一次推理 → 向量化掩码合并"** 三步，模型只跑一遍，分档是信号矩阵上的视图。

### 2.1 Step A：分档掩码先行（纯向量化，秒级，禁止循环）

- 一次 `QlibProvider("ashares", ...)` 取全 A `$amount` + `$close`（M/R 基线同源复用）→
  `unstack("instrument")` 成宽表（dates × codes）；
- **rolling 分档**（全程 pandas 向量化，不做月末循环）：

```python
adv60 = amount_wide.rolling(60, min_periods=60).mean()        # 60 日均额
pct   = adv60.rank(axis=1, pct=True)                          # 逐日截面百分位
mask_b = (pct >= lo) & (pct < hi)                             # 每档一个布尔宽表
```

- 掩码再与合格性条件按位与：上市满 L+60 日（`adv60` 非 NaN 天然涵盖）、
  主口径 **PIT 剔除 ST**（`D.instruments("st")` spans 展开成布尔宽表后取反相与）；
  附加不剔除 ST 的对照轨（与帖子可比），两轨分开报告；
- 档位：`[0,5%)`、`[5%,10%)`、`[45%,55%)`；高流动性对照**复用 csi300 已有信号**不重算；
- masks 落盘 parquet；逐日各档样本量与 ST 占比入阶段 0 报告。

### 2.2 窗口（补硬伤②，不变）

- **只用 2024-07-01 ~ 2026-07-24**（预训练截止 2024-06 之后，与论文时间隔离一致）；
- 明确写入结果文档：帖子 2024-07 之前的曲线段全部落在预训练数据内，本轮不予对照。

### 2.3 Step B：Kronos 一次性推理（唯一的重活）

- **推理宇宙 = 三档掩码的逐日并集**（先有掩码才有推理清单——顺序不可颠倒，
  否则全 A 推理约 70 小时；并集约 750 只/日 × ~500 日 ≈ **10-12 小时 GPU**）；
- canonical **mean**（N=20、T=1.0、top_p=0.9、seed=42、L=90/H=10），按日构窗
  `predict_batch`，产出**单一信号宽表** `signal_wide`（dates × union codes）；
- 按日增量落盘断点续跑（文件名带窗口标签，吸取 checkpoint 污染事故教训）；
- 分档之后**不再触碰模型**——换分档参数只动 Step A/C，零推理成本。

### 2.4 Step C：掩码合并 + 对照组（纯向量化）

```python
factor_b = signal_wide.where(mask_b)          # 档外置 NaN，即"mask 方式合并"
stacked  = factor_b.stack()                   # MultiIndex(datetime, instrument)
# → analyzer.analyze_factor(stacked, ...)     # 每档一次调用
# → qlib_bt: stacked.to_frame('score')        # NaN 即出池，天然限定档内
```

- **M**（10 日动量）= `close_wide/close_wide.shift(10) - 1`、**R** = 其取负、
  **P** = 同形状 seed 固定随机矩阵——全部是宽表向量化变换后套同一掩码，零额外取数。

### 2.5 分析与回测（补硬伤①的后半 + 硬伤③，输入即 Step C 的 stacked 序列）

1. **信号层**（`analyze_factor`，每档 × 每信号）：档内 10 分位单调性、Q10−Q1 spread、
   IC/ICIR（T+1、剔停牌一字板后的样本空间）；
2. **组合层**（`qlib_bt`，每档 × 每信号）：topk = 档内约 10%（~25 只）、
   涨跌停拦截 + 停牌跳过开启、成本按 qlib 默认（open 0.1%/close 0.15%，比帖子严）；
3. **基准双轨**：`qlib_bt` 内置 benchmark 填 `000852.SH`（中证1000，仅作展示参考）；
   **主判读基准是自算的本档 PIT 等权日收益**——`engine.get_returns()` 扣费净收益
   减去本档等权收益，得到剥离流动性/规模 beta 后的选股超额。这是补硬伤①的核心。

## 3. 预注册判读（跑之前冻结，按顺序，先否决项）

1. **门禁**：P 组在最低档的 Q10−Q1 spread 与对档等权超额均 ≈ 0（|年化|<3%）——
   不过则管线有 bug，停止；
2. **信号存在性**：最低档 `[0,5%]` 的 Kronos Q10−Q1（10 日期）spread 年化 > 0 且 t > 2
   → "池内分层区分力存活"（对应帖子图三的可信部分）；
3. **相对基线**：Kronos 的档内 spread 与对档等权超额须**同时超过 R（反转）同口径**——
   否则结论为"帖子观察到的是小盘反转，Kronos 无增量"；
4. **单调性**：`[0,5%] → [5%,10%] → [45%,55%] → csi300` 四点上 Kronos 指标单调递减
   → 支持"流动性越低越准"的方向性陈述（两段单调不全则如实记录为"部分成立"）；
5. **经济性**：最低档经涨跌停拦截 + 停牌 + 成本后的对档等权超额 > 0 才可写
   "有可实现价值"；仅信号层显著而组合层归零，结论写"统计上存在、执行上不可收割"。
