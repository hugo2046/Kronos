## 判读一：vs 市场基准（判据 S1/S2，0 线 = 双基准）

- **S1 保级通过**：中位种子（按 AER 等权排序 s100 < s102 < s101）= **s102**，
  双基准 +18.67%/+14.64% 均 > 0 → G1 从"单种子存活"升级"**多种子存活，待前向确认**"；
- **S2 附注成立**：三种子 backtest AER(等权) 全部 > 0（+14.33/+29.06/+18.67%），
  且 12 个（种子×变体）格子全正——方向性不依赖任何单一种子/变体选择；
- 免费基线 M（+36.02%）仍高于三种子 mean——"存活"与"跑赢动量"是两件事，
  判据只回答前者（M 仅参照）；
- 局限重申：两窗均在 oos1 内（半污染），"多种子存活"仍须 2026-11 forward
  结算才能摘掉"待前向确认"。

## 判读二：vs Kronos 基线（判据 S4 + 链路递进）

- **S4 跨窗一致复现 100%**：新种子 2025H2 较 F0_mean 同窗（-16.79%）改善
  s101 **+27.95pp**、s102 **+20.69pp**，均远超 +5pp 门槛（2/2 复现）；
  叠加第 5 轮 G0（F1 权重 @2025H2 +19.89pp），三种子两窗较 F0 改善全部成立；
- 微调链全貌（backtest 窗 mean AER 等权）：
  F0 **-17.23%** → F1(csi300 语料) -4.24% → G1(全 A 语料，三种子)
  **+14.33% / +29.06% / +18.67%**——"语料扩展 + 种子重训"的组合把链推过
  0 线并保持；
- 种子敏感性如实记录：三种子摆动 14.7pp（+14.33~+29.06%），与 D1 先验
  （±10~20pp）一致——**单种子点估计不得引用为强度结论**；四变体内摆动
  （如 s102 last +13.86% vs max +33.07%）同样显著，四变体纪律维持：
  判据只在 mean，记录族不挑主线。

## 局限（计划 §3 预声明 + 实测补充）

1. 三种子共享同一 G1 tokenizer（共享条款）——tokenizer 种子敏感性未检验；
   其 val 曲线两轮单调稳定，先验风险低；
2. 半污染窗上限不变：通过 ≠ 摘除"待前向确认"；
3. 种子摆动 14.7pp 实测确认——强度引用必须给区间，不给单种子点估计；
4. **登记 ≠ 交易**：G3 为研究性前瞻记录，证据等级不足以支持实盘决策。
