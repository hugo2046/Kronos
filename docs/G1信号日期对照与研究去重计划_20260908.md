## 4. 任务 B：G1 两臂对照，唯一区别是提供信号的日期

新增 `mh1_multihorizon/grid_audit.py` 与 `tests/test_g1_grid_audit.py`。只复用 `replay_corrected.py` 的市场读取、v2 重放与同路径费用分解；不得调用 baseline_suite 的旧 run_group。

| 对照臂 | 输入 |
|---|---|
| FULL | 原始 G1_mean 的完整逐日信号，按原文件实际覆盖落入 W3/W4 |
| CROPPED | 同一原始 G1_mean 文件，只保留原 MH1 对应窗口的信号日期，其余日期置 NaN |

两臂必须用同一 G1 文件，不能从不同实验文件拼一个 FULL；G1 文件路径沿用 `replay_corrected.G1_MEAN_PARQUET` 并登记 SHA256。FULL 原始缺失的信号保持缺失，不填充。

核心构造必须等价于以下数据操作，其中 `calendar` 为完整结算交易日历，`columns` 为同一冻结股票列宇宙，`mh1_dates` 取自原信号文件实际日期：

```python
full = raw_g1.reindex(index=calendar, columns=columns)
cropped = full.copy()
cropped.loc[~cropped.index.isin(mh1_dates), :] = float("nan")
```

## 5. 任务 C：差异解释与公平基准

主对照使用同一完整日历上的**策略自身净收益**与**同一指数基准**；不得把两个各自稀疏掩码得到的等权 AER 直接当成纯交易节奏效应。

- [ ] 主表每窗 FULL/CROPPED 并列：自身毛/净累计收益、净值末值、指数毛/净累计超额与年化、真实策略最大回撤、成本和、双边换手与交易日数。年化均按252，但优先读累计结果。
- [ ] 提供两组等权附表：①各臂现有 v2 掩码，标明各自有效日期，仅用于口径复现；②两臂共同的 `tradeable & full.notna() & cropped.notna()` 股票日掩码与共同有效日期，用于可比的等权对照。尾部无共同信号时不填零、不声称覆盖完整窗口。
- [ ] 以两臂首次实际输入信号不同的日期为切点，分“此前共同区间/此后区间”报告毛、净收益差与成本差；此前逐日净收益及交易应一致，考虑 delay=1 后实际差异起点不能早于相应成交。
- [ ] 若日期差异仅为连续尾部，则报告尾部持仓数量、持仓名单变化、成交日与费用；若有内部缺口，改称差异后区间，不宣称尾部单一因果。
- [ ] 净值差与成本分解分别输出，不将日收益差之和当成累计NAV差。以同一次路径的 `gross=net+cost` 构造毛收益，保持持仓路径一致。
- [ ] 判断只允许描述：FULL与CROPPED符号是否一致；裁剪是否改变收益符号；毛收益差还是费用差与净值变化同向。不得以本次对照挑更优交易日历投入使用，不重新登记G1通过/失败，不做显著性筛选。
- [ ] 即使 FULL/CROPPED 两窗均正，也只能说明这两个已观察窗口的表现，不能称“稳健盈利已证实”。若依赖裁剪，明确后续G10不能以裁剪后的正收益作为默认基准。
