## 判断口径
1. 先看固定seed CE对齐：各臂3000→6000/选点是否下降，SAM与AdamW的差距是否缩小，末1000步是否趋平。仍下降时只称仍有训练进展，不宣称收敛。
2. 经济比较：新SAM减新AdamW为核心优化器对照；各自减其3000步父版本衡量续训增量；同时分别报告相对原G1和原MC40。每日净收益差的20日配对循环block bootstrap5000次seed100，不把其CI套用于Sharpe/MDD。
3. 如果两臂都改善但SAM仍落后，结论是训练更久有益、SAM增量未获支持；如果SAM只在CE追平但经济不追平，结论是预测目标与交易目标未同步。不得因单窗收益追胜、挑seed或挑训练终点补改协议。
4. 同更新次数非等计算量、单训练seed与重复查看历史窗口限制公开披露。此次只做固定额外3000步，不以未收敛为理由无限追加。
