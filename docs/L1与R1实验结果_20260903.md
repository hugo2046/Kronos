## 1. R1 读出头换目标（终审）——RC4 触发：读出议题关闭

**问题**：G5 三头全败，死因是"架构不适"还是"回归目标不适"？

**执行**（4.2，2026-09-03 16:51~17:17）：
- 日边界重建：474 个截面日 / 141,019 样本，与冻结 g5 缓存 y **逐位对拍
  max|Δ|=0.000e+00**（IC 损失按日截面的数据完整性前提）；
- 六训（唯一变量=损失 MSE→IC，批=每日截面 ~280 只，早停段日均 RankIC 早停）：

| 训 | 用时 | 最佳 es_RankIC | epochs |
|---|---|---|---|
| R-lin s42/s43/s44 | 78.7s / 97.9s / 80.9s | +0.1074 / +0.0987 / +0.0999 | 18 / 23 / 19（早停触发） |
| R-kda s42/s43/s44 | 247.6s / 298.6s / 255.8s | +0.1010 / +0.0546 / +0.0801 | 6 / 7 / 6（早停触发） |

- 打分两窗（backtest 2026-01-01~2026-07-24 / 2025H2）落盘 12 张 parquet 后，
  引擎全表封存（`r1_objective/data/r1_backtest_results.json`，判读前未读）；
  在位者 G1_mean 复跑 +14.33% 与冻结值逐位一致（评估链路无误）。

**一次开封**（17:50，`r1_objective/data/r1_verdict.json` + `figures/r1_aer_bar.png`）：

| 头 | 中位种子 | backtest AER(idx) | backtest AER(ew) | 2025H2 AER(ew) | RC1 |
|---|---|---|---|---|---|
| R-lin | s44 | **−16.45%** | **−12.32%** | −11.69% | ✗ |
| R-kda | s43 | **−5.70%** | **−1.18%** | −26.36% | ✗ |
| （在位者 G1_mean） | — | +10.66% | +14.33% | +5.95% | — |

判读：

- **RC1 存活：双头全败**（中位种子双基准均 ≤ 0）。
- **RC2 目标效应（带内，不可判）**：R-kda 逐种子配对差（IC−MSE，G5 同头同种子）
  **+6.83pp / +13.14pp / +22.71pp 三种子同向为正**，中位 +13.14pp——排序目标
  方向一致地优于回归目标，但 ≤ 26pp 噪声底，不许"目标函数是死因"的强结论；
  R-lin 配对差 +5.00 / −11.85 / −10.37pp（s43/s44 以 G5 H-lin_s42 单锚配对，
  如实披露），中位 −10.37pp 带内。
- **RC3 对在位者**：R-lin −26.66pp / R-kda −15.51pp，均深负。
- **RC4 终审关闭：触发**——"读出议题两目标（回归/排序）× 三头族 × 两底座终审
  关闭，不做损失函数搜索"。IC 损失把 R-kda 从 G5 的中位 −14.32% 拉到 −1.18%
  （配对差 +13pp），方向正确但量级远不够：**死因主要不在回归目标**——冻结 G1
  底座隐状态上接读出头这条路，两个目标函数都没能存活。
- **注册触发：无**（RC1 未通过）。
- 与诚实先验一致（15~25%）：早停段 es_RankIC ~+0.10，样本外塌方重演（G5 同款
  病理）。

## 2. S1 工程预检（Blackwell sm_120）——编译可行，无判据

环境：RTX 5090（sm_120）/ CUDA 13.0 / torch 2.13.0+cu130 / py3.13，2026-09-03。

| 项 | 结果 |
|---|---|
| 预编译轮子 | **无**（cp313+cu13+sm120 无轮子，pip 仅解析到 sdist：causal_conv1d-1.7.0.tar.gz / mamba_ssm-2.3.2.post1.tar.gz） |
| 源码编译 | **成功**：`CUDA_HOME=/usr/local/cuda-13.0 TORCH_CUDA_ARCH_LIST=12.0 MAX_JOBS=32 pip install <sdist> --no-build-isolation`（causal_conv1d ~5min，mamba_ssm ~20min） |
| CUDA 扩展加载 | 真实加载：`causal_conv1d_fn` / `selective_scan_fn`（CUDA 实现）+ triton `selective_state_update` 可用 |
| Mamba-2 块前向/反向 | batch 8 × L 512 × d 832（expand=2→d_inner 1664, headdim 64, nheads 26, 参数 4,399,310）：**前向 3.21ms、反向 4.44ms**（5 次均值），显存峰值 0.77GB |

副作用与处置（如实记录）：mamba_ssm sdist 硬 pin `tilelang==0.1.8`，安装时把
环境里 vllm 0.27.1 声明的 tilelang 0.1.12 降到了 0.1.8——已按 **vllm 优先**恢复
tilelang 0.1.12 + apache-tvm-ffi 0.1.11，实测 mamba_ssm 导入链（含 tilelang 栈）
与 Mamba2 前向在 0.1.12 下正常；pip 元数据冲突警告保留在案。S1 若立项，建议
独立 venv 或等上游修 pin。

**供 S1 立项结论字段**：轮子=无（仅 sdist）；编译=成功；核可用=是；性能=充分
（0.77GB @ 8×512×832）。学生骨架选 Mamba-2 无工程障碍。

## 3. L1 长上下文先导——LC4 触发：长上下文议题关闭，S1 撤案

**问题**：G1 的 alpha 随上下文长度是饱和于 90、继续上涨、还是已过峰？

**执行**（4.3，2026-09-03 17:23 ~ 09-04 22:38，两夜断点续跑）：

- 数据窗重建（lookback=250，min_len=261 剔除阈值）：8392 PIT 并集 / 5657 可得 /
  覆盖 67.4%；train 5,536 符号 11,980,417 行（2011-01-04~2024-12-31）；
- **最小声明修正**（先于任何训练/评估反馈发现，G5 ffn 512→256 同款裁决规则，
  非搜索）：官方 val_time_range（2025-01~06，约 117 交易日）< lookback=250 的
  window=261，val 可采样窗口数为 0、CE 早停将退化为 epoch1 定型（4.1 门禁测试
  实测拦下）。将 L250-ft 的 val_time_range 最小扩展为 **2024-01-02~2025-06-30**
  （val 窗口 524,749 个），train 切分/语料/超参/种子逐字不动；修正冻结于
  `test_l1_config` 允许差异集。
- L250-ft 训练：G1 配方 seed=100、Kronos-base 起点、G1 tokenizer 冻结，
  epochs=15 全程 **2:00:39**，val CE 平台在 **2.4328**（best_model=末段 epoch）；
- 八组推理时间线（backtest：ZS100 3.1h → ZS101 3.1h → ZS102 3.1h → L500 6.0h →
  FT 3.1h；2025h2：ZS100 3.2h → ZS101 3.0h → ZS102 2.9h），合计 ~24h，与计划
  预算 ~25h 一致；覆盖随窗长自然收缩（L250 ~kept 283-288/300、halt 剔 12-16；
  L500 kept 274、halt 剔 23——长窗含停牌概率更高，臂定义固有）；
- DuckDB 追加对拍：5 臂 × (mean, backtest 中位日) 逐值比对 **max|Δ|=0.0e+00**
  ×5；引擎全表封存（judge 前未读）；三锚重算与冻结逐位一致
  （+14.3332/+29.0588/+18.6706 vs +14.3330/+29.0590/+18.6710）。

**一次开封**（09-04 22:54，`l1_context/data/l1_verdict.json` +
`figures/l1_aer_bar.png`；backtest 窗 AER 等权）：

| 组 | AER(ew) | 组 | AER(ew) |
|---|---|---|---|
| L90 锚 s100/s101/s102 | +14.33% / +29.06% / +18.67% | L1L250ZS100_mean | +4.80% |
| L1L250ZS101_mean | +4.82% | L1L250ZS102_mean | +5.54% |
| L1L500ZS100_mean | **−19.03%** | L1L250FT100_mean | **−4.49%** |

配对差（mean 变体，vs 同种子 L90 锚）：

```
d_ft（L250-ft − L90 s100）       = −18.83pp
d_zs[s100 / s101 / s102]         = −9.53 / −24.23 / −13.13pp（中位 −13.13pp）
d_500（L500-zs − L250-zs, s100） = −23.83pp（描述性：250→500 单调走低）
```

判读：

- **LC1 靶存在：两腿皆负**（d_ft ≤ 0 且 d_zs 中位 ≤ 0）→ 未通过；
- **LC4 关闭：触发**——"上下文于 90 附近饱和/过峰，长上下文议题关闭，S1 撤案"；
  按 §5 纪律不做 L 网格（250/500 之外不加点）、不做损失/几何搜索；
- LC3 显著：全部配对差带内（|max|=24.2pp < 26pp），只做方向性描述——但三种子
  + ft + L500 五个方向读数**全部同向为负**，方向一致性本身是信息；
- **注册：无**（LC1 未通过）；
- **如实披露的窗口依赖**（描述性，不进判据）：2025H2 窗方向相反——L250-zs 三
  种子 AER(ew) +27.18/+19.85/+19.33%，对同窗 L90 锚配对差 **+21.23/+8.69/
  +15.43pp 全正**。两窗方向相反 = 长上下文效应强窗口依赖（与"论文窗口正结果是
  窗口运气"的历史教训同构）；冻结判据锚定 backtest 窗，判读不变，但该现象作为
  机制线索留档：若未来重开长上下文议题，须先解释两窗相反。

**对 S1 的含义**：S1（蒸馏换骨架突破 512 上限）的全部上行赌注 = "更长上下文有
增量"。L1 在 Kronos-base 512 上限内的 250/500 双点均为负增量 → S1 撤案
（LC4 冻结条款）。§2 的 Blackwell 核预检记录保留为工程事实，供任何未来
Mamba-2 用途参考，不构成 S1 立项依据。

## 6. 结论速览

- **R1：读出议题终审关闭（RC4）**——IC 损失方向性优于 MSE（R-kda 三种子配对差
  同向 +7~+23pp）但救不活任何头；死因主要不在回归目标。
- **L1：长上下文议题关闭（LC4），S1 撤案**——backtest 窗五个方向读数全负
  （zs 三种子 −9.5/−24.2/−13.1pp、ft −18.8pp、500−250 再 −23.8pp）；上下文于
  90 附近饱和/过峰。留档机制线索：2025H2 窗方向相反（+8.7~+21.2pp 全正），
  长上下文效应强窗口依赖，重开须先解释。
- **S1 预检：Mamba-2 在 sm_120 编译可行、性能充分**（工程事实保留，不构成
  S1 立项依据——L1 已撤案）。
- 两实验均无注册臂；forward 结算对照不受影响；G1@L90 在位者地位不变。
