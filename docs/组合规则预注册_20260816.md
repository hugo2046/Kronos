## 2. 规则定义（冻结，结算前不可修改）

**C1（三种子集成）**：对每个 (date, code)，
`C1_signal = mean(G1_s100_mean, G1_s101_mean, G1_s102_mean)`
——只用 S1 判据家族的三个种子（100/101/102；s103/104 是判读后执行的诊断种子，
**不进集成**）；只用 mean 变体（canonical 主线，不碰四变体记录族）；缺任一种子值的
(date, code) 剔除该股当日信号。

**C2（G1×MA200 状态切换）**：决策日 t，
- 登记表 `gate`（000300.SH 收盘 > MA200，G3 逐日盖章值）为 **True** → 当日用 **M** 信号；
- **False** → 当日用 **C1** 集成信号。
迟补日（manifest `late=true`）沿用其盖章 gate 值，结算时对迟补日单独做剔除敏感性。

**组合口径**（两规则同）：canonical 引擎逐字复用——csi300 池、k=50/n=5/min_hold=5/
单边 15bp、双基准（000300.SH + 同池等权）。
