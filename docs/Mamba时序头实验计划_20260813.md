## 1. 假说与单一变量设计

**假说 H**：Kronos 冻结隐表征含 oos 存活的截面信息，提取量由头的时序混合机制决定
（B2 线性=取不出，B3 KDA=取出一部分）。**选择性 SSM（Mamba）的输入依赖 Δ 门控
（"哪些日子该记该忘"）能比 KDA 的线性注意力取出更多。**

**单一变量纪律**：新头与 B3 相比，**只许换头内的时序混合块**。以下全部逐字复用 B3：
冻结主干与输入口径（窗口 z-score+clip5+stamp）、训练切分与 purge、标签、损失、
优化器族（AdamW wd=0.01 lr=3e-4）、batch=128、epochs≤50、patience=5（早停段日均
RankIC）、`forward(x_norm, stamp) -> score[B]` 契约。

**容量对齐**：新头可训练参数须落在 **[0.8M, 1.3M]**（B3 ~1M 的 ±30%），排除
"参数更多所以更强"的解释。测试强制断言。

## 2. 臂与冻结超参（跑前冻结，禁止追加/调整）

| 臂 | 结构 | 种子 | 性质 |
|---|---|---|---|
| **T1** | 冻结主干 → `input_proj(832→256)` → Mamba `ResidualBlock×2`（d_model=256, d_state=16, expand=2, dt_rank=auto=16, d_conv=4）→ `RMSNorm` → 末步 → `linear(256→1)` | 42/43/44 三种子 | 候选主臂 |
| T0 | B3 既有 checkpoint（seed=42），**不重训** | 42 | 在位对照（数字已封盘，直接引用） |
| D1 | B3 结构按原协议**新训**两个种子 | 43/44 | 种子稳健性诊断（检验"B3 幸存是否种子运气"） |

- T1 参数核算（须测试断言）：input_proj 832×256≈213K + 2×MambaBlock(d_inner=512:
  in_proj 262K + out_proj 131K + x_proj 24.6K + dt_proj 8.2K + conv 2K ≈ 428K)
  + head 257 ≈ **1.07M** ∈ [0.8M, 1.3M] ✓；
- T1 三种子独立训练，**主判据用三种子按 oos1 AER(等权) 排序的中位种子**（防单种子运气，
  也防挑最好）；三种子结果全部报告；
- D1 与 T1 同预算同协议，唯一区别是头结构（KDA vs Mamba）——D1 顺带构成
  "同容量同协议下两个头族 × 三种子"的 2×3 对照矩阵（T0 计入 KDA 族 seed=42）。

## 5. 阶段 3：引擎评估与预注册判定

全部 checkpoint 定型后，一次性过引擎（csi300 + csi500 × paper + oos1 × 双基准），
然后统一判读——**判读前不看任何 oos1 数字**。

**预注册判据（跑前冻结）**：

1. **主判据（存活）**：T1 中位种子 oos1 双池 AER(等权) > 0 **且** AER(指数) > 0 →
   "**Mamba 头双池存活，待前向确认**"；
2. **强判据（改进）**：T1 中位种子 oos1 两池 AER(等权) 均 ≥ B3(T0) 对应池 +2pp
   （即 csi300 ≥ +3.97%、csi500 ≥ +5.55%）→ "**选择性 SSM 头优于 KDA 头，假说 H
   获支持，待前向确认**"；
3. **表示层判据**：KDA 族（T0+D1，3 种子）与 Mamba 族（T1，3 种子）中各自 ≥2 个种子
   oos1 csi300 AER(等权) > 0 → "**隐表征含 oos 存活截面信息**的证据升级为
   双头族×多种子，待前向确认"；
4. **脆弱性判据（D1）**：D1 两种子 oos1 csi300 AER(等权) 均 ≤ 0 → "**B3 幸存疑似
   种子运气**"，如实记录并降级 B3 结论（写回结果文档，引用上轮文档但不改动它）；
5. 全败（T1 三种子 oos1 全负且 D1 全负）→ "**隐表征 oos 存活信息假说证伪，
   路径 B 线路关闭**"，如实记录，不做任何结构/超参搜索。
