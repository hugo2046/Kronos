## 1. 规则定义（冻结，结算前不可修改）

对每个交易日 t（G3 登记表为唯一数据源）：

1. `C1_i = mean(G1_s100_mean_i, G1_s101_mean_i, G1_s102_mean_i)`
   （即 `组合规则预注册_20260816.md` 的 C1 信号，缺任一种子值剔除该股当日）；
2. 截面标准化：`z_C1 = zscore(C1)`、`z_M = zscore(M)`（按当日有效股票池，均值 0 方差 1）；
3. `C3_i = 0.5 × z_C1_i + 0.5 × z_M_i`（任一侧缺值剔除该股当日）；
4. 按 C3 排序进 canonical 引擎：csi300 池、k=50/n=5/min_hold=5/单边 15bp、
   双基准（000300.SH + 同池等权）。

**权重永久冻结条款**：0.5/0.5 为零信息先验，注册后**不可调整**；结算文档中禁止出现
任何"若权重为 x 则更好"的事后复盘或权重敏感性分析——那是被本项目三十一次
证伪教训封死的搜索行为。
